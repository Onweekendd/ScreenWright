# Screenwright Artifact App Template

Screenwright Artifact 应用的标准起点，固定使用 Vue 3、Vite、TypeScript 和 Tailwind CSS。

```bash
pnpm install
pnpm dev
```

常用命令：

- `pnpm dev`：启动开发预览服务器。
- `pnpm typecheck`：执行 Vue/TypeScript 类型检查；`pnpm check-types` 是仓库内兼容别名。
- `pnpm test`：运行单元测试。
- `pnpm build`：生成可由静态资源服务器托管的 `dist`。

实际项目请优先通过 `npx create-screenwright-app <目录>` 创建，不要直接复制并修改这个模板目录。
