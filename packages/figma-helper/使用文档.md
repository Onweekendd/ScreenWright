# FunBI 规范助手 —— 使用文档

FunBI 规范助手是一个 Figma 插件，帮助设计师按照 FunBI 低代码平台的结构规范命名节点、检查合并关系、预览转化结构，并完成图片资源的导出与上传。

---

## 前置准备：安装证书

插件需要连接内网服务，**首次使用前必须安装附带的 `funai.crt` 证书**。详见随包的 `证书安装说明.md`。

---

## 界面概览

```
┌─────────────────────────────┐
│  FunBI 规范助手        v1.x │
├─────────────────────────────┤
│  当前选中   N 个节点         │
│  [节点类型] 节点名称          │
├──────────────────────────────┤
│  命名 │ 合并 │ 结构 │ 导出 │ 模板 │
├──────────────────────────────┤
│  （各 Tab 内容区）            │
└──────────────────────────────┘
```

插件顶部始终显示当前在 Figma 中选中的节点。选中单个节点后，**合并**、**结构**、**导出** Tab 会自动触发扫描。

---

## 命名约定速查

转化时，节点名称的**后缀**决定它在 BI 中的角色：

| 后缀 | 转化目标 | 关键约束 |
|------|---------|---------|
| `-exhibition` | 根节点 | 整个展项唯一 |
| `-panel` | 动态面板（主容器） | 替代旧版 `-theme` |
| `-status` | 动态面板的一个状态 | 子节点必须是 `-merge` FRAME |
| `-merge` | 合并层（叠加合成） | Figma type **必须为 FRAME** |
| `-subtab` | 选项卡组件 | 必须是 Figma 组件，跨 frame 同名自动合并 |
| `-image` | 图片组件 | 用于需要单独导出/上传的图片占位节点 |
| `-group` | 分组（可选） | 仅用于组织，不影响转化逻辑 |
| `TEXT 节点` | 富文本组件 | Figma 原生文字节点，无需特殊后缀 |

## Tab 功能说明

### 命名 Tab

用于快速为选中节点加上规范后缀，以及检查当前选中范围内的命名问题。

**命名后缀**

- 选中一个或多个节点后，点击后缀按钮即可应用。
- 选中单个节点：在节点名称上追加/替换后缀。
- 选中多个节点：将所有选中节点**包裹成一个新的 Group**，并以后缀命名该 Group。

**模式（单选时可用）**

- **替换已有规范后缀**：若节点名已有规范后缀（如 `-panel`、`-merge` 等），替换为新后缀。
- **追加到末尾**：无论现有名称如何，直接在末尾拼接新后缀。

**命名规范检查**

选中单个节点后，插件自动扫描其子树，找出**不符合命名约定**的节点（例如 `-merge` 节点的 Figma type 不是 FRAME）。点击列表中的问题项可直接在画布上定位该节点。

---

### 合并 Tab

帮助确认 `-merge` 合并关系是否正确配置。选中单个节点后自动分析。

**分析场景 A：选中 `-merge` Frame 本身**

显示同一 `-panel` 下的所有其他 `-merge` Frame，帮助确认有哪些 frame 将被叠加合并。点击列表项可在画布上定位对应 frame。

**分析场景 B：选中 `-merge` Frame 内部的子节点**

显示同一 `-panel` 下其他 `-merge` Frame 中，与当前节点**对应的同名节点**的匹配状态：

| 状态标记 | 含义 |
|---------|------|
| ✓（绿色） | 已在该 frame 中找到同名、同位置的对应节点（公共节点） |
| ~（黄色） | 找到疑似对应节点，但名称不完全一致 |
| ✗（红色） | 该 frame 中未找到对应节点（当前节点为独有节点，将归入内嵌动态面板） |

对于黄色「疑似」项，可点击 **同步** 按钮将对方节点重命名为与当前节点相同的名称，使其变为公共节点。

**全部选中**：点击可同时选中当前节点及所有已匹配的对应节点，便于批量检查。

---

### 结构 Tab

以树形视图预览选中节点（通常为 `-exhibition` 根节点）按规范扁平化后的结构，帮助在导出前直观确认层级是否符合预期。

- 点击树中的节点名称可在画布上定位该节点。
- 使用「全展开」/「全收起」按钮控制树的展开状态。
- 若提示「未找到可析构的节点」，说明所选节点不含符合规范的子结构。

---

### 导出 Tab

管理 `-image` 节点的图片资源，以及上传整个节点数据。选中单个节点后自动扫描其子树中的所有 `-image` 节点。

**图片导出**

- 列表显示扫描到的所有 `-image` 节点及其所在路径，支持按名称/ID 搜索。
- **导出为 ZIP**：将筛选范围内的图片节点导出为 PNG，打包成 ZIP 文件下载到本地。
- **上传 minio**：将图片直接上传到内网 MinIO 对象存储（需已安装证书并连接内网）。

**上传节点数据**（仅当选中的是 `-exhibition` 根节点时显示）

- **上传节点数据**：将整棵节点树的结构数据序列化后上传到内网服务，供 AI 转化流程使用。

---

### 模板 Tab

提供符合规范的 Figma 组件模板，一键创建到画布，避免手动搭建时结构出错。

**选项卡（3项）**

点击后在画布上生成一个标准的 `-subtab` 组件，包含：
- 1 个 `-subtab` 容器组件
- 3 个 tabitem 组件集，每个包含 `State=active` 和 `State=noaction` 两个变体
- 每个 tabitem 内含 `-image` 背景图占位节点和文字节点，均使用绝对定位

生成后根据实际内容修改标题、替换背景图即可。

---

## 推荐工作流

```
1. 设计完成后，选中 -exhibition 根节点
2. 【命名 Tab】检查命名规范，修复问题节点
3. 【合并 Tab】逐一选中 -merge frame 内的关键子节点，确认跨 frame 匹配关系
4.   → 对黄色「疑似」项点击「同步」统一命名
5. 【结构 Tab】预览整体扁平化结构，确认层级符合预期
6. 【导出 Tab】导出/上传图片资源，上传节点数据
```

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 合并 Tab 显示「该节点不在任何 -merge frame 中」 | 所选节点的父级 frame 未命名为 `-merge` | 检查父 frame 命名 |
| 导出 / 上传按钮点击无响应 | 证书未安装或 Figma 未重启 | 安装证书后重启 Figma Desktop |
| 命名检查报错「type 不符合约束」 | `-merge` 节点的 Figma type 不是 FRAME（如是 Group） | 将该节点转换为 Frame |
| 结构 Tab 提示「未找到可析构的节点」 | 选中节点不含 `-panel` 子节点 | 确认已选中 `-exhibition` 根节点 |
| `-subtab` 跨 frame 未被识别为公共节点 | 两个 frame 中的 subtab 不是同一个 Figma 组件 | 复制组件实例，勿手动绘制 |
