# FunBI 规范助手 —— 证书安装说明

使用本插件前，需在本机安装随包附带的 `funai.crt` 证书，否则插件将无法连接内网服务。**每台电脑只需安装一次。**

---

## Windows 安装步骤

1. 双击 `funai.crt`，在弹出窗口中点击 **安装证书**
2. 存储位置选 **本地计算机** → 下一步
3. 选 **将所有的证书都放入下列存储** → 点击 **浏览**
4. 选择 **受信任的根证书颁发机构** → 确定 → 下一步 → 完成
5. 重启 Figma Desktop

---

## macOS 安装步骤

1. 双击 `funai.crt`，证书会被添加到「钥匙串访问」
2. 打开「钥匙串访问」，在「系统」或「登录」钥匙串中找到 `localhost`
3. 双击该证书 → 展开「信任」 → 将「使用此证书时」改为 **始终信任**
4. 关闭窗口（会要求输入密码确认）
5. 重启 Figma Desktop

---

## 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 请求一直失败 / 无响应 | 证书未安装或安装位置错误 | 确认安装到「受信任的根证书颁发机构」 |
| 安装后仍然报错 | Figma 未重启 | 完全退出后重新打开 Figma Desktop |
| macOS 提示「不受信任」 | 证书未手动设置为始终信任 | 在钥匙串访问中手动改为「始终信任」 |
