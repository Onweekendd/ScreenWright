# UE模板 (ft-unreal-engine)

## dataChart 数据格式

| 字段 | 类型 | 说明 |
|------|------|------|
| text | string | 文本内容 |

## option 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| muted | boolean | true | 是否静音 |
| initLoad | boolean | false | 是否初始化加载 |
| id | string | "" | UE实例ID |
| url | string | "" | UE服务地址 |
| publishPath | string | "" | 发布路径 |
| cover | string | "" | 封面图片路径 |
| version | string | "1" | 版本号 |
| sceneJsonPath | string | "" | 场景JSON配置路径 |
| sceneList | array | [] | 场景列表 |
| bluePrintOption | array | [] | 蓝图选项列表 |
