# 页面刷新 (pageReload)

## dataChart 数据格式

无数据字段（data为空数组）

## option 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| icon | string | "version-test/assets/defaultImg/shuaxin.png" | 刷新图标路径 |
| iconHeight | number | 50 | 图标高度 |
| iconWidth | number | 50 | 图标宽度 |
| opacity | number | 1 | 透明度(0-1) |
| pageReloadType | string | "click" | 刷新类型(click/auto) |
| pageReloadTypeClick | string | "0" | 点击刷新模式(0/1) |
