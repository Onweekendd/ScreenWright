# UE像素流v2 (ue-pixel-streaming)

## dataChart 数据格式

| 字段 | 类型 | 说明 |
|------|------|------|
| text | string | 文本内容 |

## option 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| muted | boolean | true | 是否静音 |
| initLoad | boolean | false | 是否初始化加载 |
| pixelStreamingUrl | string | "" | 像素流服务地址 |
| cover | string | "" | 封面图片路径 |
