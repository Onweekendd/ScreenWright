# UE容器beta (ue-vessel)

## dataChart 数据格式

| 字段 | 类型 | 说明 |
|------|------|------|
| text | string | 文本内容 |

## option 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| msgName | string | "" | 消息通道名称 |
| fontSize | number | 16 | 字号 |
| fontWeight | boolean | false | 是否加粗 |
| fontStyle | boolean | false | 是否斜体 |
| fontFamily | string | "sans-serif" | 字体 |
| fontColor | string | "rgba(255, 255, 255, 1)" | 字体颜色 |
| backgroundColor | string | "rgba(255, 255, 255, 0)" | 背景颜色 |
