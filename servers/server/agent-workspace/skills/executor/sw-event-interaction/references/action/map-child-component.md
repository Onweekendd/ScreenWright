# switchMapChildComponentVisible — 切换地图子组件显隐

适用于 `echartGlmap` 组件，控制地图子组件的显示或隐藏。

## 字段

| 字段路径 | 类型 | 说明 |
|---------|------|------|
| `mapChildComponent.nameList` | string[] | 子组件名称列表 |
| `mapChildComponent.childComponentInfoList` | any[] | 子组件信息列表 |
| `mapChildComponent.visible` | string | 可见性状态：`"show"` / `"hide"` / `"switch"`（显隐切换） |
