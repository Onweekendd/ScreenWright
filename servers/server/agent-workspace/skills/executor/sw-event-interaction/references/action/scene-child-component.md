# switchSceneChildComponentVisible — 切换场景子组件显隐

控制 3D 场景中子组件的显示或隐藏。

## 字段

| 字段路径 | 类型 | 说明 |
|---------|------|------|
| `sceneChildComponent.nameList` | string[] | 子组件名称列表 |
| `sceneChildComponent.childComponentInfoList` | any[] | 子组件信息列表 |
| `sceneChildComponent.visible` | string | 可见性状态：`"show"` / `"hide"` / `"switch"`（显隐切换） |
