# handleSceneObjExplosion — 场景对象爆炸动画

对 3D 场景中的对象执行爆炸/拆解动画。

## 字段

| 字段路径 | 类型 | 说明 |
|---------|------|------|
| `sceneObjectExplosion.index` | string | 对象ID |
| `sceneObjectExplosion.lidName` | string | 机盖名称 |
| `sceneObjectExplosion.baseName` | string | 机底名称 |
| `sceneObjectExplosion.type` | string | 爆炸类型 |
