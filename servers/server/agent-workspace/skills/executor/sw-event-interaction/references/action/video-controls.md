# 视频控制类

以下视频控制行为均只需设置 `animation.delay`（动画延迟时间，毫秒）：

- `videoToPlay` — 播放视频
- `videoToPause` — 暂停视频
- `videoToStop` — 停止视频
- `videoToRestart` — 重播视频
- `videoToFullscreen` — 视频全屏
- `videoToUnmuted` — 取消静音
- `videoToMuted` — 静音
- `videoToAudioUp` — 音量增大
- `videoToAudioDown` — 音量减小
- `videoToFastin` — 快进
- `videoToRewind` — 快退

## 字段

| 字段路径 | 类型 | 说明 |
|---------|------|------|
| `animation.delay` | number (ms) | 动画延迟时间（毫秒） |
