# TodoWrite 工具使用规则

TodoWrite 只用于主 agent **直接执行多步骤工作**时展示进度。委派给子 agent 的施工单元应使用 Task V2，不要用 Todo 代替。

详细用法用 `skill(name="sw-task-management")` 加载。

## 快速规则

- **不触发执行**：TodoWrite 只更新 UI 清单，不会委派或执行任务。
- **全量替换**：每次调用传入仍需保留的完整 `todos` 数组。
- **唯一进行项**：同一列表最多一个 `in_progress`。
- **及时更新**：开始前标记 `in_progress`，实际完成后立即标记 `completed`。
- **双形式描述**：每项都提供 `content`（目标）和 `activeForm`（进行时展示）。
- **包含验证**：修改代码、配置或数据流时，应包含明确的验证步骤。
- **自动清空**：非空列表全部完成后，工具自动清空活动清单。
- **避免重复**：如果同一粒度的工作已由 Task V2 跟踪，不要再复制到 Todo。
