# 多选框 (formCheckbox)

**组件标识**: formCheckbox | **中文名**: 多选框 | **分类**: 交互

## 描述

多选框组件用于在一组选项中进行多选操作，支持设置最小和最大可选数量。每个选项可以设置选中状态和禁用状态，常用于数据筛选、条件过滤等场景。

**与其他组件的区别**：
- 区别于单选框（swSingleSelectedLegend）：本组件允许同时选中多个选项，单选框只能选一个
- 区别于图例（swLegend）：本组件为简单多选交互，图例有复选框图标样式的精细配置和子类嵌套支持

## 别名/同义词

复选框 多选按钮 checkbox 多选

## 适用场景

多类别数据筛选 条件过滤 多维度选择 控制图表数据系列
