# 导航菜单 (formNavMenu)

**组件标识**: formNavMenu | **中文名**: 导航菜单 | **分类**: 交互

## 描述

导航菜单组件提供垂直或水平方向的导航功能，支持多级子菜单、折叠展开、图标配置等。可以设置默认激活项、唯一展开模式等交互行为，适用于大屏侧边导航、页面跳转等场景。

**与其他组件的区别**：
- 区别于选项卡（subtabs）：本组件支持多级嵌套子菜单和图标配置，更适合层级较深的导航场景；选项卡更适合平级标签页切换

## 别名/同义词

侧边导航 菜单 导航栏 navMenu

## 适用场景

大屏侧边导航 多级菜单选择 页面主导航 控制组件显隐 区域城市层级选择
