# 滑块 (formSlider)

**组件标识**: formSlider | **中文名**: 滑块 | **分类**: 交互

## 描述

滑块组件用于通过拖动滑块来选择一个数值或数值范围，支持设置最小值、最大值和步长。可以显示为水平或垂直方向，支持范围选择模式，常用于参数调节、数值筛选等场景。

**与其他组件的区别**：
- 区别于滚动选择器（scrollPicker）：本组件用于连续数值选择，滚动选择器用于离散选项的滚动选择

## 别名/同义词

滑动条 滑块选择器 slider range slider

## 适用场景

音量亮度调节 数值范围筛选 动画速度控制 数据刷新间隔 参数调节
