# 多选选项卡 (multi-subtabs)

**组件标识**: multi-subtabs | **中文名**: 多选选项卡 | **分类**: 交互

## 描述

多选选项卡组件提供多选标签页功能，允许同时选中多个标签。支持行列布局配置、自动播放和滚动，可以为不同系列配置独立的样式，适用于多维度数据筛选、多条件组合选择等场景。

**与其他组件的区别**：
- 区别于选项卡（subtabs）：本组件允许同时选中多个标签，选项卡只能单选
- 区别于多选框（formCheckbox）：功能类似但样式不同，本组件使用按钮样式，多选框使用复选框样式

## 别名/同义词

多选标签页 多选tab multi tabs

## 适用场景

多维度数据展示 多条件组合筛选 多图表联动控制 多标签同时选中
