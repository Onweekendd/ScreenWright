# 点状时间轴 (pointTimeline)

**组件标识**: pointTimeline | **中文名**: 点状时间轴 | **分类**: 交互

## 描述

点状时间轴组件以垂直或水平的点状时间线形式展示事件信息，每个时间点包含时间和描述文本。支持交叉显示、动画循环播放，适用于企业发展历程、项目里程碑等时间线展示场景。

**与其他组件的区别**：
- 区别于时间轴（swTimerShaft）：本组件每个节点可显示标题和描述文本，信息更丰富；时间轴为简洁的水平线形式

## 别名/同义词

点状时间线 point timeline

## 适用场景

企业发展历程 项目里程碑 历史事件按时间浏览 时间线展示
