# 滚动选项卡 (roll-subtabs)

**组件标识**: roll-subtabs | **中文名**: 滚动选项卡 | **分类**: 交互

## 描述

滚动选项卡组件在选项卡基础上增加了滚动功能，当选项数量超出显示区域时可以通过箭头按钮滚动浏览。支持水平或垂直滚动方向，适用于选项较多需要滚动切换的场景。

**与其他组件的区别**：
- 区别于选项卡（subtabs）：本组件增加左右箭头导航和滚动功能，适合选项数量较多的场景；选项卡适合选项固定在可视范围内

## 别名/同义词

滚动标签页 可滚动tab rolling tabs

## 适用场景

选项较多标签页切换 数据类别分类筛选 滚动浏览导航标签
