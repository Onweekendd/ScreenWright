# 滚动选择器 (scrollPicker)

**组件标识**: scrollPicker | **中文名**: 滚动选择器 | **分类**: 交互

## 描述

滚动选择器组件提供类似手机滚轮的选择体验，通过上下滚动来选择选项。支持配置显示数量、排列方式、自动轮播，选中的选项会以放大或高亮样式突出显示，适用于垂直方向的选项选择场景。

**与其他组件的区别**：
- 区别于下拉框（swCustomSelect）：本组件始终展示所有选项通过滚动定位选择
- 区别于选项卡（subtabs）：本组件通常垂直排列有3D滚轮效果

## 别名/同义词

滚轮选择器 picker 滚动选择

## 适用场景

日期年月日选择 垂直分类选项选择 滚动效果选择交互
