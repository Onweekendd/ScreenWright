# 选项卡 (subtabs)

**组件标识**: subtabs | **中文名**: 选项卡 | **分类**: 交互

## 描述

选项卡组件提供单选标签页切换功能，支持行列布局、自动播放和滚动条配置。可以为默认、激活和悬停三种状态设置不同的样式，还支持多系列样式配置，适用于数据维度切换、面板切换等场景。

**与其他组件的区别**：
- 区别于多选选项卡（multi-subtabs）：本组件同一时间只能选中一个标签，多选选项卡允许选中多个
- 区别于滚动选项卡（roll-subtabs）：本组件不支持箭头滚动导航，是最基础的标签页组件

## 别名/同义词

标签页 tab 选项卡切换

## 适用场景

数据视图切换 图表维度切换 面板标签页导航
