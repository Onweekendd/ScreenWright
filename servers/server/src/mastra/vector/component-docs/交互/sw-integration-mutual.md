# 集成交互控制 (sw-integration-mutual)

**组件标识**: sw-integration-mutual | **中文名**: 集成交互控制 | **分类**: 交互

## 描述

集成交互控制组件用于在集成场景中提供可点击的交互区域，支持悬停效果和背景图片配置。该组件是交互组件的精简版本，适用于外部系统集成场景中的简单点击交互。

**与其他组件的区别**：
- 区别于交互组件（sw-mutual）：本组件是面向外部系统集成的精简版本，配置项更少，没有AI聊天功能；交互组件功能更丰富

## 别名/同义词

集成交互 集成控制区域

## 适用场景

集成页面可点击区域 外部系统交互控制 热区触发组件联动
