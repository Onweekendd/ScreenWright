# 交互组件 (sw-mutual)

**组件标识**: sw-mutual | **中文名**: 交互组件 | **分类**: 交互

## 描述

交互组件用于在大屏上创建可点击的交互区域，支持悬停效果、背景图片和CSS变换。该组件可以配置AI聊天弹窗功能，点击后弹出问答界面，适用于智能大屏交互场景。

**与其他组件的区别**：
- 区别于集成交互控制（sw-integration-mutual）：本组件功能更丰富，支持AI问答弹窗、透明度设置等；集成交互控制是面向外部系统集成的精简版本

## 别名/同义词

交互区域 点击区域 热区

## 适用场景

大屏热区点击触发 场景切换数据联动 AI问答弹窗交互 装饰性交互元素
