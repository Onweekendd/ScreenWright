# 搜索框组件 (sw-search)

**组件标识**: sw-search | **中文名**: 搜索框组件 | **分类**: 交互

## 描述

搜索框组件提供关键词搜索功能，支持自定义输入框样式、占位文本、边框、背景和搜索按钮。可以配置按钮的位置、图标和样式，适用于数据筛选、关键词检索等场景。

**与其他组件的区别**：
- 区别于下拉框（swCustomSelect）：本组件为自由文本输入，适合模糊搜索；下拉框从预定义选项中选择，适合精确选择
- 区别于语音控件（sw-voice-control）：本组件为键盘文本输入，语音控件为语音输入

## 别名/同义词

搜索框 搜索 search

## 适用场景

关键词搜索数据 实时搜索过滤 数据查询输入控件
