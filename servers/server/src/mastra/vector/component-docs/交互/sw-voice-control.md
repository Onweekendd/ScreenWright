# 语音控件beta (sw-voice-control)

**组件标识**: sw-voice-control | **中文名**: 语音控件beta | **分类**: 交互

## 描述

语音控件组件提供语音识别功能，支持唤醒词、热词配置和多种识别模式。通过点击语音按钮进行语音输入，识别结果以文本形式返回，适用于语音搜索、语音指令等智能交互场景。

**与其他组件的区别**：
- 区别于搜索框（sw-search）：本组件为语音输入，搜索框为键盘文本输入，两者形成互补

## 别名/同义词

语音识别 语音控制 voice

## 适用场景

语音搜索数据 语音指令触发交互 AI语音问答 智能大屏语音控制
