# 多级下拉框 (swCascader)

**组件标识**: swCascader | **中文名**: 多级下拉框 | **分类**: 交互

## 描述

多级下拉框组件用于从具有层级关系的数据中进行逐级选择，如省市区选择、组织架构选择等。数据支持递归嵌套的子级选项，支持自定义各级菜单的字体样式和背景。

**与其他组件的区别**：
- 区别于下拉框（swCustomSelect）：本组件支持递归嵌套子级选项，适合层级较深的选择场景；下拉框只支持扁平选项列表

## 别名/同义词

级联选择器 多级选择器 cascader

## 适用场景

省市区三级联动 组织架构层级选择 多级分类目录选择 层级数据逐级筛选
