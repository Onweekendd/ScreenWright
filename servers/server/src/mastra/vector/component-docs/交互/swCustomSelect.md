# 下拉框 (swCustomSelect)

**组件标识**: swCustomSelect | **中文名**: 下拉框 | **分类**: 交互

## 描述

下拉框组件提供单选下拉选择功能，支持自定义选择框样式、下拉菜单样式和悬停效果。可以设置占位文本、默认选中项和禁用选项，适用于数据筛选、条件选择等场景。

**与其他组件的区别**：
- 区别于多级下拉框（swCascader）：本组件只支持扁平选项列表，不支持子级嵌套
- 区别于搜索框（sw-search）：本组件从预定义选项中选择，搜索框为自由文本输入

## 别名/同义词

选择器 自定义下拉框 select

## 适用场景

城市列表选择 筛选条件选择 分类类型选择 表单下拉控件
