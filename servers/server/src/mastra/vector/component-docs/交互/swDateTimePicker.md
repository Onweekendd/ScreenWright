# 时间范围选择器 (swDateTimePicker)

**组件标识**: swDateTimePicker | **中文名**: 时间范围选择器 | **分类**: 交互

## 描述

时间范围选择器组件用于选择一个时间范围，支持设置日期格式和时间格式。可以配置日历弹窗的显示位置和样式，常用于数据筛选、报表时间范围选择等场景。

**与其他组件的区别**：
- 区别于时间轴（swTimerShaft）：本组件通过日历控件手动选择时间范围，时间轴通过点击预定义时间节点切换数据

## 别名/同义词

日期时间选择器 日期范围 时间选择 dateTimePicker

## 适用场景

数据查询时间范围 报表时间区间 时间段数据筛选 起止时间选择
