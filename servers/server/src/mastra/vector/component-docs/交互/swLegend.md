# 图例 (swLegend)

**组件标识**: swLegend | **中文名**: 图例 | **分类**: 交互

## 描述

图例组件提供带复选框的图例列表，支持选中/取消选中操作来控制关联数据的显示。每个图例项可以有子类选项，支持自定义选中/未选中状态的字体样式和背景。

**与其他组件的区别**：
- 区别于多选框（formCheckbox）：本组件有复选框的精细样式配置和子类嵌套支持
- 区别于单选框（swSingleSelectedLegend）：本组件允许多选，单选框只能选一个

## 别名/同义词

多选图例 图例复选框 legend

## 适用场景

控制图表数据系列 数据维度筛选 多选过滤关联图表
