# 单选框 (swSingleSelectedLegend)

**组件标识**: swSingleSelectedLegend | **中文名**: 单选框 | **分类**: 交互

## 描述

单选框组件提供单选操作功能，同一时间只能选中一个选项。支持自定义复选框样式和标签的选中/未选中状态样式，适用于数据维度切换、单条件筛选等场景。

**与其他组件的区别**：
- 区别于多选框（formCheckbox）和图例（swLegend）：本组件同一时间只能选中一个选项
- 区别于选项卡（subtabs）：功能类似但样式不同，本组件使用复选框样式，选项卡使用按钮样式

## 别名/同义词

单选图例 单选按钮 radio

## 适用场景

维度切换 年季月切换 图表数据视图切换 单条件筛选
