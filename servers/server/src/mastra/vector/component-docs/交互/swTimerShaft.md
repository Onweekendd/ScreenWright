# 时间轴 (swTimerShaft)

**组件标识**: swTimerShaft | **中文名**: 时间轴 | **分类**: 交互

## 描述

时间轴组件以水平时间线的形式展示时间节点，支持点击切换不同时间点来联动数据。可以配置自动播放和循环，每个节点有默认和激活两种样式状态，适用于按时间维度浏览数据的场景。

**与其他组件的区别**：
- 区别于点状时间轴（pointTimeline）：本组件为水平线性节点布局，点状时间轴可显示更丰富的标题和描述
- 区别于时间范围选择器（swDateTimePicker）：本组件点击预定义节点切换数据，时间范围选择器手动选择时间范围

## 别名/同义词

时间线 timeline 时间滑块

## 适用场景

按年份浏览历史数据 时间维度数据联动 项目里程碑展示 发展历程浏览
