# 面积折线图 (echartareaLine)

**组件标识**: echartareaLine | **中文名**: 面积折线图 | **分类**: 图表 > 折线图

## 描述

用折线连接数据点，并用彩色面积填充线条下方区域。展示数据变化趋势，同时强调数据的累积或占比关系。支持多系列对比、透明度调节和平滑曲线。

**与其他趋势图的区别**：
- 区别于折线图（echartline）：本组件用面积填充强调数据累积，折线图为纯线条
- 区别于柱状图（echartbar）：本组件展示连续趋势，柱状图用于离散数据对比
- 区别于堆叠占比图（echartoverlapBar）：本组件用面积，堆叠占比图用柱子堆叠

## 别名/同义词

面积图 area图 区域填充图 趋势面积 堆叠面积 流量图 用户增长面积 数据积累图 区域趋势 面积占比

## 适用场景

用户增长趋势展示 浏览量或访问量堆叠 流量来源占比 收入构成变化 市场占有率变化 设备在线状态累计 能源消耗堆叠 库存变化趋势 人员投入配置 多维度累积数据
