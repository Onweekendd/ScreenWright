# 柱状图 (echartbar)

**组件标识**: echartbar | **中文名**: 柱状图 | **分类**: 图表 > 柱形图

## 描述

竖向柱状图，用于比较不同类别的数值大小，是最常用的对比类图表。适合展示各类别（部门、地区、产品、时间段）之间的数量差异，支持多系列并排展示和堆叠模式。

**与其他柱图的区别**：
- 区别于条形图（echartstripBar）：本组件为竖向，条形图为横向
- 区别于双向条形图（echartbothWayStripBar）：本组件单向，双向条形图两侧分别展示两个系列
- 区别于排名图（echartrank）：本组件标准对比，排名图带排序样式
- 区别于折线柱形图（echartlineAndBar）：本组件纯柱状，不含折线

## 别名/同义词

柱图 bar图 竖向柱图 纵向柱状图 柱形图 对比柱状图 分组柱状图 堆叠柱状图 直方图 垂直柱图

## 适用场景

部门销售额对比 各地区数据比较 月度季度年度对比 同期对比 历年对比 排行展示 多维度数值对比 KPI完成情况 预算与实际对比 产品销量对比
