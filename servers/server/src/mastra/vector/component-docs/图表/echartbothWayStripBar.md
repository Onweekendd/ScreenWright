# 双向条形图 (echartbothWayStripBar)

**组件标识**: echartbothWayStripBar | **中文名**: 双向条形图 | **分类**: 图表 > 柱形图

## 描述

双向对比的水平柱状图，以中心为基准左右两侧分别展示两个系列数据，适合展示正负值对比、两个维度的对立数据、两组数据的对称对比。支持极值高亮、数值标签显示、独立边距配置和双向排列样式。

**与其他柱图的区别**：
- 区别于条形图（echartstripBar）：本组件左右双向分布，条形图为单向
- 区别于柱状图（echartbar）：本组件为横向，柱状图为竖向
- 区别于折线柱形图（echartlineAndBar）：本组件纯条形，不含折线混合
- 区别于排名图（echartrank）：本组件用于双向对比，排名图用于单序列排序
- 区别于象形图（echartpictorialbar）：本组件标准几何形状，象形图可使用图标/图片
