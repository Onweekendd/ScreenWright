# 特殊型折线图 (echartdoubleValueLine)

**组件标识**: echartdoubleValueLine | **中文名**: 特殊型折线图 | **分类**: 图表 > 项目图表

## 描述

带有特殊数据标记和连接样式的折线图，适合展示趋势数据并突出关键数据点。

**与其他图表的区别**：
- 区别于折线图（echartline）：本图支持特殊标记和连接样式，折线图为标准样式
- 区别于面积折线图（echartareaLine）：本图填充区域可选，面积图为默认填充
- 区别于散点图（echartscatter）：本图带连线，散点图为独立点

## 别名/同义词

特殊折线图 标记折线图 趋势折线图 双值折线图 高亮折线图

## 适用场景

趋势数据展示 关键数据点标记 异常数据突出 销售趋势分析 用户增长趋势 访问量趋势展示
