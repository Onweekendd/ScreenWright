# Top10气泡图 (echarteffectScatter)

**组件标识**: echarteffectScatter | **中文名**: Top10气泡图 | **分类**: 图表 > 项目图表

## 描述

带涟漪特效效果的散点图，常用于展示Top排名数据，气泡大小反映数值大小。

**与其他图表的区别**：
- 区别于散点图（echartscatter）：本图带涟漪动画特效，散点图为静态点
- 区别于排名图（echartrankBar）：本图用气泡大小展示，排名图用柱体高度
- 区别于饼图（echartpie）：本图气泡大小反映数值，饼图为扇区角度

## 别名/同义词

Top10气泡图 动态散点图 涟漪散点图 气泡排名图 特效散点图 动态气泡图

## 适用场景

Top10排名展示 热门商品排行 活跃用户排行 热门文章排行 重点产品排名 关键指标展示
