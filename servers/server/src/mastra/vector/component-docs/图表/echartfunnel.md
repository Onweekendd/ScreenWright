# 漏斗图 (echartfunnel)

**组件标识**: echartfunnel | **中文名**: 漏斗图 | **分类**: 图表 > 其他

## 描述

用梯形面积展示数据的逐层递减过程，适合表现转化率、筛选流程等场景。每一层代表一个阶段，面积表示数值大小，支持百分比计算和层级对比。

**与其他图表的区别**：
- 区别于饼图（echartpie）：本组件展示流程转化，饼图展示占比分布
- 区别于柱状图（echartbar）：本组件强调递减趋势，柱状图用于分类对比
- 区别于桑基图（echartsankey）：本组件单向递减，桑基图展示流向关系
