# 关系图 (echartgraph)

**组件标识**: echartgraph | **中文名**: 关系图 | **分类**: 图表 > 其他

## 描述

用于展示复杂节点关系的力导向图，通过节点和连线表示实体间的关联关系。支持自定义节点样式、连线和标签，适合展示社交网络、知识图谱、组织架构等场景。

**与其他图表的区别**：
- 区别于桑基图（echartsankey）：本图为多对多复杂关系网，桑基图为单向流向展示
- 区别于雷达图（echartradar）：本图为节点间任意连接关系，雷达图为径向轴维度对比
- 区别于折线图（echartline）：本图为节点关系网络，折线图为时间序列趋势
