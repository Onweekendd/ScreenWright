# 增长率柱状图 (echartgrowthRateBar)

**组件标识**: echartgrowthRateBar | **中文名**: 增长率柱状图 | **分类**: 图表 > 项目图表

## 描述

专门用于展示增长率数据的柱状图，支持正负值显示，适合展示同比增长、环比增长等数据。

**与其他图表的区别**：
- 区别于柱状图（echartbar）：本图专为增长率设计，支持正负值零轴对齐
- 区别于折线柱形图（echartlineAndBar）：本图纯柱状展示增长率，组合图展示绝对值和趋势
- 区别于双向条形图（echartbothWayStripBar）：本图柱状展示增长率，双向条形图为横向对比

## 别名/同义词

增长率柱状图 增长柱图 增幅柱状图 同比增长图 环比增长图 正负柱状图

## 适用场景

同比增长率展示 环比增长率分析 月度增长率对比 季度增长率展示 用户增长率分析 营收增长率对比
