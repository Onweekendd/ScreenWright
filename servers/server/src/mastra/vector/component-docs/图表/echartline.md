# 折线图 (echartline)

**组件标识**: echartline | **中文名**: 折线图 | **分类**: 图表 > 折线图

## 描述

用折线连接多个数据点，展示数据变化趋势。适合展示时间序列数据或连续数据的走势变化，支持多系列对比、添加面积填充和平滑曲线效果。

**与其他趋势图的区别**：
- 区别于柱状图（echartbar）：本组件展示连续趋势，柱状图用于离散数据对比
- 区别于面积折线图（echartareaLine）：本组件为纯线条，面积折线图用彩色面积填充区域
- 区别于特殊型折线图（echartdoubleValueLine）：本组件标准折线，特殊型支持多轴和双值显示
- 区别于3D柱状折线图（echartthreedBarAndLine）：本组件纯折线，折线柱形混合图包含柱子

## 别名/同义词

趋势图 trend图 线图 连线图 数据走势 时间序列图 变化曲线 折线走势 多线对比

## 适用场景

时间序列数据展示 历史数据走势 用户增长趋势 股票价格走势 实时监测数据 按日期的销售额 网站访问量趋势 设备运行状态 KPI达成进展 预测值vs实际值对比
