# 折线柱形图 (echartlineAndBar)

**组件标识**: echartlineAndBar | **中文名**: 折线柱形图 | **分类**: 图表 > 柱形图

## 描述

混合图表，在同一个图表中同时展示柱形图和折线图，支持双Y轴左右对齐，适合展示不同度量单位的数据关联趋势。可自由切换每个系列的图表类型（柱形/折线）、独立设置颜色、透明度、数值标签等样式。

**与其他柱图的区别**：
- 区别于柱状图（echartbar）：本组件混合图表，可同时包含柱形和折线
- 区别于折线图（echartline）：本组件默认包含柱形，折线图为纯折线
- 区别于条形图（echartstripBar）：本组件可混合折线，条形图纯条形
- 区别于面积折线图（echartareaLine）：本组件柱形+折线组合，面积图为折线+面积填充
- 区别于3D折线柱形图（echartthreedBarAndLine）：本组件2D平面，3D图为立体效果

## 别名/同义词

折线柱形图 柱状折线图 混合图表 组合图 柱折图 双轴图 趋势对比图 量价图 关联分析图 复合图 组合图表

## 适用场景

销售额与增长率对比 产量与合格率 访问量与转化率 成本与利润对比 订单量与客单价 流量与点击率 两个度量单位的关联数据 多指标趋势分析 量价分析 同期对比分析
