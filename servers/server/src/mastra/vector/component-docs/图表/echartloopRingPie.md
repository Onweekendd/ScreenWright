# 轮播环形饼图 (echartloopRingPie)

**组件标识**: echartloopRingPie | **中文名**: 轮播环形饼图 | **分类**: 图表 > 饼图

## 描述

环形饼图支持数据自动轮播切换展示。当数据项较多时，按设定时间间隔循环显示部分数据，避免图表过于拥挤。适合展示动态排行榜、实时占比变化等场景，能够突出显示当前轮播到的数据项。

**与其他饼图的区别**：
- 区别于标准饼图（echartpie）：本组件为环形样式且支持轮播动画，标准饼图为完整圆形静态展示
- 区别于3D饼图（echartthreePie）：本组件为2D环形，3D饼图为立体效果
- 区别于层叠玫瑰图（echartpluralRosePie）：本组件用扇区表示占比，玫瑰图用花瓣长度表示数值且支持坐标轴配置
- 区别于环形饼图（echartthreeQuartersPie）：本组件支持轮播动画，环形饼图静态展示
