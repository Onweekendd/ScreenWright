# 总数排名图 (echartmultiplyRankBar)

**组件标识**: echartmultiplyRankBar | **中文名**: 总数排名图 | **分类**: 图表 > 项目图表

## 描述

支持多系列对比的排名柱状图，适合展示不同类别在同一指标下的排名对比。

**与其他图表的区别**：
- 区别于排名图（echartrankBar）：本图支持多系列对比，排名图为单系列
- 区别于柱状图（echartbar）：本图专为排名场景优化，支持数值标签和轴标签自定义
- 区别于斑马柱状折线图（echartzebraBarAndLine）：本图纯柱状，组合图含折线

## 别名/同义词

总数排名图 多系列排名图 对比排名图 多维度排名图 竞品对比排名图

## 适用场景

多品牌销量排名对比 多部门业绩排名对比 多产品线排名对比 竞品分析排名 多地区数据排名对比
