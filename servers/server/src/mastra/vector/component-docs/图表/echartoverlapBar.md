# 堆叠占比图 (echartoverlapBar)

**组件标识**: echartoverlapBar | **中文名**: 堆叠占比图 | **分类**: 图表 > 项目图表

## 描述

柱状堆叠图，展示各部分占总体的百分比，适合展示构成分析数据。

**与其他图表的区别**：
- 区别于饼图（echartpie）：本图为柱状堆叠展示占比，饼图为环形角度展示
- 区别于柱状图（echartbar）：本图柱体堆叠显示占比，柱状图为并列或分组显示
- 区别于象形图（echartpictorialbar）：本图标准柱状堆叠，象形图为自定义图形

## 别名/同义词

堆叠占比图 堆叠柱状图 占比堆叠图 百分比柱图 构成分析图 堆叠百分比图

## 适用场景

成本构成分析 用户构成分析 产品组合占比 收入结构分析 库存构成展示 部门人员构成
