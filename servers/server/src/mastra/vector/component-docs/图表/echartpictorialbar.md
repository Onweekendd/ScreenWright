# 象形图 (echartpictorialbar)

**组件标识**: echartpictorialbar | **中文名**: 象形图 | **分类**: 图表 > 柱形图

## 描述

使用图标、图片或自定义图形代替传统柱形条的图表，通过重复图形数量或缩放图形大小表示数值大小，直观生动地展示数据。支持上传自定义图标、设置图形宽度、图形颜色、数值标签等样式，适合需要视觉冲击力或强化的主题展示。

**与其他柱图的区别**：
- 区别于柱状图（echartbar）：本组件使用图标/图片代替柱形，柱状图为几何形状
- 区别于条形图（echartstripBar）：本组件可使用图形图标，条形图为标准矩形
- 区别于排名图（echartrank）：本组件象形展示，排名图为标准条形
- 区别于双向条形图（echartbothWayStripBar）：本组件使用图形，双向图使用几何条形
- 区别于折线柱形图（echartlineAndBar）：本组件纯象形柱形，不含折线混合
