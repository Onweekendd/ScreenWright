# 饼图 (echartpie)

**组件标识**: echartpie | **中文名**: 饼图 | **分类**: 图表 > 饼图

## 描述

用圆形扇区展示数据的占比关系。适合展示各类别在总体中的百分比，支持点击交互和数值标签显示。常用于市场份额、预算分配、用户分布等场景。

**与其他饼图的区别**：
- 区别于3D饼图（echartthreePie）：本组件为2D标准饼图，3D饼图为立体效果
- 区别于环形饼图（echartthreeQuartersPie）：本组件为完整圆形，环形饼图为圆环形状
- 区别于轮播环形饼图（echartloopRingPie）：本组件静态展示，轮播版支持数据循环切换
- 区别于层叠玫瑰图（echartpluralRosePie）：本组件简单占比，玫瑰图用花瓣长度表示数值

## 别名/同义词

占比图 比例图 分布图 份额图 百分比图 圆形图 饼形统计 扇形图 类别分布 组成比例

## 适用场景

市场份额占比 预算分配比例 用户类型分布 销售额占比 流量来源分布 部门人员比例 产品销售构成 设备类型分布 客户群体划分 收入来源占比
