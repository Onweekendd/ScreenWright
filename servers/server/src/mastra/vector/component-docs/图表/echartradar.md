# 雷达图 (echartradar)

**组件标识**: echartradar | **中文名**: 雷达图 | **分类**: 图表 > 其他

## 描述

用于多维度数据对比分析的雷达图，通过从中心点向外辐射的轴线展示多个指标的相对表现。每个系列形成闭合多边形区域，便于直观比较不同对象在多个维度上的综合表现。

**与其他图表的区别**：
- 区别于散点图（echartscatter）：本图为径向轴多维度对比，散点图为双轴分布分析
- 区别于折线图（echartline）：本图为径向轴线形成闭合区域，折线图为直角坐标系趋势展示
- 区别于柱状图（echartbar）：本图为多指标综合评分对比，柱状图为单指标分类对比
