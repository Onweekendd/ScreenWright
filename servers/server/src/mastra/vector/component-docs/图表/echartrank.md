# 排名图 (echartrank)

**组件标识**: echartrank | **中文名**: 排名图 | **分类**: 图表 > 柱形图

## 描述

自动排序的水平柱状图，突出展示排名或排序后的数据对比，支持升序或降序排列。每个排名系列具有独立的排名标签背景、类目标签和数值标签配置，适合展示Top排行榜、名次对比、等级分布等排序场景。

**与其他柱图的区别**：
- 区别于条形图（echartstripBar）：本组件自动排序，条形图保持原始顺序
- 区别于柱状图（echartbar）：本组件为横向且强调排序，柱状图为竖向
- 区别于双向条形图（echartbothWayStripBar）：本组件单向排序，双向图用于左右对比
- 区别于象形图（echartpictorialbar）：本组件标准柱形，象形图使用图标
- 区别于折线柱形图（echartlineAndBar）：本组件纯柱形且强调排序，折线柱图为混合图表
