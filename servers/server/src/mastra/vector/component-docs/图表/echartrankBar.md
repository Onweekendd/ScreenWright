# 排名图 (echartrankBar)

**组件标识**: echartrankBar | **中文名**: 排名图 | **分类**: 图表 > 项目图表

## 描述

专门用于展示排名数据的柱状图，简化配置选项，支持数值标签和轴标签自定义。

**与其他图表的区别**：
- 区别于柱状图（echartbar）：本图为简化配置的排名展示，柱状图为完整配置
- 区别于斑马柱状图（echartzebra）：本图只有全局配置，不支持坐标轴详细配置
- 区别于总数排名图（echartmultiplyRankBar）：本图无双系列，总数排名图支持多系列对比

## 别名/同义词

排名图 排名柱状图 简化柱图 排名榜 排行榜柱图

## 适用场景

销售排名展示 员工绩效排名 产品销量排名 分数排名 竞技排行 积分排行榜
