# 桑基图 (echartsankey)

**组件标识**: echartsankey | **中文名**: 桑基图 | **分类**: 图表 > 其他

## 描述

用于展示流向数据的桑基图，通过带状线条表示不同节点之间的数据流动关系，线条粗细反映流量大小。适合展示用户流转、资金流向、能量传递等场景。

**与其他图表的区别**：
- 区别于关系图（echartgraph）：本图为单向流向展示，关系图为复杂节点关系网
- 区别于矩形树图（echarttreemap）：本图为节点间流向连接，矩形树图为层级面积占比
- 区别于漏斗图（echartfunnel）：本图为多对多流向关系，漏斗图为单一流程逐级筛选
