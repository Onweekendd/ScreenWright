# 刻度饼图 (echartscalePie)

**组件标识**: echartscalePie | **中文名**: 刻度饼图 | **分类**: 图表 > 项目图表

## 描述

带有刻度线的饼图，适合展示精确的占比数据，刻度线帮助用户更准确地读数。

**与其他图表的区别**：
- 区别于饼图（echartpie）：本图带刻度线，饼图为标准样式
- 区别于仪表盘（echartprogress）：本图为完整饼图带刻度，仪表盘为半圆进度展示
- 区别于环形饼图（echartthreeQuartersPie）：本图可实心可空心，重点在刻度线

## 别名/同义词

刻度饼图 带刻度饼图 精确饼图 刻度环形图 标尺饼图

## 适用场景

精确占比展示 财务分配占比 预算精确分配 统计数据占比 需要精确读数的场景
