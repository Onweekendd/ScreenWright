# 散点图 (echartscatter)

**组件标识**: echartscatter | **中文名**: 散点图 | **分类**: 图表 > 散点图

## 描述

用点的位置表示两个维度的数据值，用点的大小或颜色表示第三个维度。适合展示数据之间的相关性和分布规律，支持气泡大小映射和颜色渐变。

**与其他点图的区别**：
- 区别于柱状图（echartbar）：本组件展示多维数据关系，柱状图用于分类对比
- 区别于气泡图（echarteffectScatter）：本组件标准散点，气泡图有脉冲效果
- 区别于折线图（echartline）：本组件展示相关性，折线图展示趋势
- 区别于热力图：本组件用点表示，热力图用色块表示

## 别名/同义词

气泡图 散点 相关性分析 点图 XY图 对比分析 分布图 两轴对比 数据相关性 多维散布

## 适用场景

价格与销量相关性 身高与体重相关性 投入与产出分析 风险与收益分析 工资与经验关系 客户群体分类 营销效果分析 设备性能对比 用户行为分析 地理位置分布
