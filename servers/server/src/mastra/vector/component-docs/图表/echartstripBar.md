# 条形图 (echartstripBar)

**组件标识**: echartstripBar | **中文名**: 条形图 | **分类**: 图表 > 柱形图

## 描述

横向柱状图，用水平柱子长度表示数值大小，适合展示长标签的分类数据对比。支持多系列并排展示、堆叠模式、数值标签显示和极值高亮。

**与其他柱图的区别**：
- 区别于柱状图（echartbar）：本组件为横向，柱状图为竖向
- 区别于双向条形图（echartbothWayStripBar）：本组件单向，双向条形图两侧分别展示两个系列
- 区别于排名图（echartrank）：本组件标准对比，排名图带排序样式
- 区别于折线柱形图（echartlineAndBar）：本组件纯条形，不含折线

## 别名/同义词

横向柱图 条形图 bar图 水平柱状图 横向对比 柱形图 条形对比 分类排行 横向统计

## 适用场景

部门销售额对比 产品销量排行 地区数据对比 员工绩效排名 月度业绩对比 客户收入等级 长标签分类 项目投入对比 KPI完成情况
