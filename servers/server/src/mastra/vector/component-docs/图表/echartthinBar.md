# 细长柱状图 (echartthinBar)

**组件标识**: echartthinBar | **中文名**: 细长柱状图 | **分类**: 图表 > 项目图表

## 描述

柱体宽度较细的柱状图，适合展示大量数据项的场景。支持排序、高亮和自定义柱体样式。

**与其他图表的区别**：
- 区别于柱状图（echartbar）：本图柱体更细，适合数据项较多的场景
- 区别于斑马柱状图（echartzebra）：本图使用专门的细长柱样式组件
- 区别于条形图（echartstripBar）：本图为竖向柱体，条形图为横向柱体

## 别名/同义词

细长柱状图 细柱图 窄柱状图 密集柱图 多项柱状图 精细柱图

## 适用场景

大量数据项展示 日活跃用户统计 月份销售数据排行 员工积分排名 各城市数据对比 产品销量排行
