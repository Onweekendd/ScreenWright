# 3D饼图 (echartthreePie)

**组件标识**: echartthreePie | **中文名**: 3D饼图 | **分类**: 图表 > 饼图

## 描述

带立体透视效果的饼图，扇区有厚度和3D旋转角度。适合需要增强视觉效果的大屏展示，支持鼠标旋转查看。

**与其他饼图的区别**：
- 区别于饼图（echartpie）：本组件为3D立体效果，饼图为2D平面
- 区别于层叠玫瑰图（echartpluralRosePie）：本组件3D效果，层叠玫瑰图为2D多层
- 区别于轮播环形饼图（echartloopRingPie）：本组件静态3D，轮播版为2D轮播

## 别名/同义词

立体饼图 三维饼图 3D占比图 空间饼图 透视饼图 立体占比 厚度饼图 3D分布图

## 适用场景

大屏数据展示 产品占比可视化 需要视觉增强的场景 销售额占比分析 市场份额展示 动态数据大屏 品类占比展示
