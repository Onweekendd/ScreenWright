# 环形饼图 (echartthreeQuartersPie)

**组件标识**: echartthreeQuartersPie | **中文名**: 环形饼图 | **分类**: 图表 > 项目图表

## 描述

中心镂空的饼图，支持自定义环形宽度和样式。适合展示占比数据的同时在中心放置总结信息。

**与其他图表的区别**：
- 区别于饼图（echartpie）：本图中心镂空，饼图为实心
- 区别于轮播环形饼图（echartloopRingPie）：本图静态展示，轮播版支持轮播切换
- 区别于3D饼图（echartthreePie）：本图为2D平面，3D饼图为立体效果

## 别名/同义词

环形饼图 甜甜圈图 空心饼图 圆环图 环形占比图 甜甜圈占比图

## 适用场景

占比数据大屏展示 产品销售占比 预算分配展示 市场份额分析 用户类型分布 类目销售占比
