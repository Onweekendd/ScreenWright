# 3D柱状图 (echartthreedBar)

**组件标识**: echartthreedBar | **中文名**: 3D柱状图 | **分类**: 图表 > 柱形图

## 描述

具有立体透视效果的柱状图，每个柱体具有顶部、侧面、底部三个不同颜色的面，形成3D视觉效果。支持设置柱体宽度、柱体颜色（渐变或单色）、顶部颜色、底部颜色、数值标签等样式，适合需要视觉冲击力或立体化展示的数据场景。

**与其他柱图的区别**：
- 区别于柱状图（echartbar）：本组件具有3D立体效果，柱状图为2D平面
- 区别于3D折线柱形图（echartthreedBarAndLine）：本组件纯柱形，3D折线柱形图可混合折线
- 区别于象形图（echartpictorialbar）：本组件通过颜色立体感，象形图使用图标/图片
- 区别于条形图（echartstripBar）：本组件竖向且3D效果，条形图为横向2D
- 区别于排名图（echartrank）：本组件强调立体视觉效果，排名图强调排序
