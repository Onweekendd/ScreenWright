# 3D柱状折线图 (echartthreedBarAndLine)

**组件标识**: echartthreedBarAndLine | **中文名**: 3D柱状折线图 | **分类**: 图表 > 项目图表

## 描述

3D柱状图和折线图的组合图表，柱体带3D立体效果，适合大屏展示增强视觉效果。

**与其他图表的区别**：
- 区别于折线柱形图（echartlineAndBar）：本图柱体为3D立体效果，折线柱形图为2D平面
- 区别于3D柱状图（echartthreedBar）：本图增加折线系列，3D柱状图为纯柱状
- 区别于斑马柱状折线图（echartzebraBarAndLine）：本图为3D效果，斑马版为2D斑马纹

## 别名/同义词

3D柱状折线图 3D组合图 立体柱线图 3D柱折混合图

## 适用场景

大屏数据展示 销量和趋势对比 3D可视化增强 产品销量和增长 大屏炫酷展示
