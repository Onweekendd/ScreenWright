# 矩形树图 (echarttreemap)

**组件标识**: echarttreemap | **中文名**: 矩形树图 | **分类**: 图表 > 其他

## 描述

用于展示层级数据占比的矩形树图，通过嵌套矩形面积反映数据大小，支持多层级展示。适合展示文件目录大小、产品分类占比、地区销售额分布等场景。

**与其他图表的区别**：
- 区别于饼图（echartpie）：本图为矩形面积展示层级占比，饼图为环形角度展示单一层级
- 区别于桑基图（echartsankey）：本图为层级面积占比，桑基图为节点间流向关系
- 区别于漏斗图（echartfunnel）：本图为多层级并列展示，漏斗图为单一流程逐级筛选

## 别名/同义词

矩形树图 树图 面积树图 层级矩形图 目录树图 文件大小图 分类占比图 层级占比图 嵌套矩形图

## 适用场景

文件目录大小分析 产品分类占比展示 地区销售额分布 组织架构层级展示 预算分配可视化 股票组合占比 市场份额分析
