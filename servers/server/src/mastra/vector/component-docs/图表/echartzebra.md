# 斑马柱状图 (echartzebra)

**组件标识**: echartzebra | **中文名**: 斑马柱状图 | **分类**: 图表 > 项目图表

## 描述

带有斑马纹效果的柱状图，支持排序、高亮和间隔着色。适合展示排名数据，通过斑马纹增强视觉区分度。

**与其他图表的区别**：
- 区别于柱状图（echartbar）：本图支持斑马纹间隔着色，柱状图为单一颜色或渐变
- 区别于细长柱状图（echartthinBar）：本图柱体宽度可调范围更大，细长柱状图固定细长样式
- 区别于排名图（echartrank）：本图支持完整坐标轴配置，排名图为简化配置

## 别名/同义词

斑马柱状图 斑马图 间隔柱状图 条纹柱图 交替色柱图 高亮柱状图 可排序柱状图 斑马条纹图

## 适用场景

销售排名展示 产品销量对比 部门业绩排名 分数排名统计 员工绩效排名 竞品对比分析 各地区数据排名 班级成绩排名
