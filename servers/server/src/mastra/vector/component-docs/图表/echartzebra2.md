# 斑马柱状图2 (echartzebra2)

**组件标识**: echartzebra2 | **中文名**: 斑马柱状图2 | **分类**: 图表 > 项目图表

## 描述

斑马柱状图的另一种实现版本，支持完整的系列配置和提示框配置。

**与其他图表的区别**：
- 区别于斑马柱状图（echartzebra）：本图支持完整配置选项（全局、坐标轴、系列、提示框），斑马柱状图为简化配置
- 区别于柱状图（echartbar）：本图支持斑马纹间隔着色，柱状图为单一颜色或渐变

## 别名/同义词

斑马柱状图2 斑马图完整版 增强斑马柱图 全配置斑马图

## 适用场景

销售排名展示 产品销量对比 部门业绩排名 需要完整配置的斑马纹柱状图
