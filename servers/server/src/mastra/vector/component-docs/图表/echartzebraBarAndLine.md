# 斑马柱状折线图 (echartzebraBarAndLine)

**组件标识**: echartzebraBarAndLine | **中文名**: 斑马柱状折线图 | **分类**: 图表 > 项目图表

## 描述

柱状图和折线图的组合图表，柱体支持斑马纹效果，适合同时展示绝对值和趋势。

**与其他图表的区别**：
- 区别于折线柱形图（echartlineAndBar）：本图柱体支持斑马纹，折线柱形图为标准柱体
- 区别于斑马柱状图（echartzebra）：本图增加折线系列展示趋势，斑马柱状图为纯柱状
- 区别于折线图（echartline）：本图柱线组合，折线图为单一折线

## 别名/同义词

斑马柱状折线图 斑马组合图 柱线组合图 斑马折线柱图 柱折混合图

## 适用场景

销量和增长率对比 订单量和金额分析 访问量和转化率 库存和周转率 销售目标和达成率
