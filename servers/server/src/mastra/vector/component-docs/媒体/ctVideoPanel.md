# 视频面板 (ctVideoPanel)

**组件标识**: ctVideoPanel | **中文名**: 视频面板 | **分类**: 媒体

## 描述

支持多视频网格布局的监控面板组件，可按行列网格同时展示多个视频画面。每个视频项具有独立的标签名称，支持视频自动播放、循环播放、静音、自动隐藏等控制。提供丰富的滤镜效果（高斯模糊、亮度、对比度、灰度、色调、反色、饱和度、褐色）和阴影效果。支持自动翻页和手动翻页，翻页动画可选。每个视频项可配置背景色、背景图、边框装饰、文字标签样式（字号、字体、颜色、阴影等）。分页器具有独立的样式配置，包括选中态和未选中态两套样式。支持海康视频播放模式。

**与其他媒体组件的区别**：
- 区别于 swswiper（轮播图）：ctVideoPanel 展示视频内容而非图片，支持多视频同时显示的网格布局。
- 区别于 swSwiperCard（轮播卡片）：ctVideoPanel 是视频网格监控面板，支持分页浏览多路视频；swSwiperCard 是3D卡片轮播。
- 区别于 sw-open-video（开场视频）：ctVideoPanel 支持多视频同时显示和网格布局分页，适用于监控场景；sw-open-video 是单一视频播放并带按钮交互，适用于开场场景。ctVideoPanel 是媒体组件中功能最复杂的组件，配置字段最多。
