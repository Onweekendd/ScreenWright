# 音频 (sw-embed-audio)

**组件标识**: sw-embed-audio | **中文名**: 音频 | **分类**: 媒体

## 描述

音频播放组件，用于在大屏中嵌入和播放音频内容。支持自动播放、循环播放等基础控制，可选择是否显示播放控件以及是否在播放后自动隐藏控件。适合背景音乐、语音播报等场景。

**核心功能**：
- 支持音频自动播放和循环播放
- 可控制是否显示播放控件
- 支持播放后自动隐藏控件

**与其他媒体组件的区别**：
- 区别于视频（swvideo）：本组件仅播放音频内容（无画面），视频组件播放视频（含画面和声音）
- 区别于iframe（swiframe）：本组件专门播放音频，iframe用于嵌入网页内容

## 适用场景

大屏背景音乐 语音播报 音效播放 音频内容嵌入 提示音 背景音频循环播放
