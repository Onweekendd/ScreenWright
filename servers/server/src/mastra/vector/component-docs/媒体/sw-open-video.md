# 开场视频 (sw-open-video)

**组件标识**: sw-open-video | **中文名**: 开场视频 | **分类**: 媒体

## 描述

用于大屏开场展示的视频播放组件，支持视频自动播放、循环播放、静音等基础控制。提供丰富的视频滤镜效果，包括高斯模糊、亮度、对比度、灰度、色调、反色、饱和度、褐色等调节。支持3D旋转、阴影效果和混合模式。最大特点是支持一个可自定义的"进入系统"按钮，按钮可以是文字类型或图片类型，可配置按钮图标、字体样式、文字阴影等。

**与其他媒体组件的区别**：
- 区别于 swswiper（轮播图）：sw-open-video 播放视频内容而非图片轮播，且具有一个可自定义的"进入系统"按钮用于交互跳转。
- 区别于 swSwiperCard（轮播卡片）：sw-open-video 是单一视频播放器，具有按钮交互功能；swSwiperCard 是多卡片3D轮播展示。
- 区别于 ctVideoPanel（视频面板）：sw-open-video 是单个视频播放，ctVideoPanel 支持多视频网格布局和分页。sw-open-video 独有按钮配置功能，适用于大屏开场场景。
