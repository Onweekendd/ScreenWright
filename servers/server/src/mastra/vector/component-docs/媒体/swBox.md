# 矩形 (swBox)

**组件标识**: swBox | **中文名**: 矩形 | **分类**: 媒体

## 描述

纯 CSS 盒子，data 为 []。默认透明，用于底板、蒙层、色块和边框。

**核心功能**：

- background：纯色或渐变背景；border：边框
- borderRadius：圆角，数字为 px，字符串按 CSS
- boxShadow：外阴影、内阴影和发光；backdropFilter：毛玻璃
- opacity：透明度（0～1）；clipPath：切角、斜边裁剪
- transform：CSS 变换；animation：内置关键帧动画
- pointerEvents：默认 false，鼠标事件穿透；true 响应鼠标

**组件区别**：

- swBox 绘制样式装饰；swimg 展示图片文件。

## 别名/同义词

矩形 方块 盒子 rectangle box 背景板 遮罩 渐变块 发光边框

## 适用场景

卡片底板 图表背景 半透明蒙层 渐变装饰 圆角面板 分隔条 切角面板 毛玻璃
