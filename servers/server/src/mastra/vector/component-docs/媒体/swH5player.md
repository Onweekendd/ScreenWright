# h5player (swH5player)

**组件标识**: swH5player | **中文名**: h5player | **分类**: 媒体

## 描述

H5视频流播放器组件，专门用于在大屏中播放实时视频流。支持WebSocket等流媒体协议接入，提供边框样式、背景颜色和分屏显示配置。分屏功能可以在同一个组件区域内同时展示多个视频画面。

**核心功能**：
- 支持视频流协议播放（如WebSocket流）
- 支持分屏显示，可同时展示多个视频源
- 提供边框样式和背景颜色自定义

**与其他媒体组件的区别**：
- 区别于视频（swvideo）：本组件专用于播放视频流（WebSocket等协议），视频组件播放标准视频文件（MP4等）
- 区别于iframe（swiframe）：本组件专门播放视频流，iframe用于嵌入完整的网页内容
- 区别于音频（sw-embed-audio）：本组件播放视频流（含画面），音频组件仅播放声音

监控视频流实时展示 直播画面嵌入 视频流监控大屏 实时画面分屏显示 流媒体播放
