# 轮播卡片 (swSwiperCard)

**组件标识**: swSwiperCard | **中文名**: 轮播卡片 | **分类**: 媒体

## 描述

基于3D旋转效果的卡片轮播组件，支持多张卡片围绕中心轴排列并自动旋转切换。每张卡片包含标题、正文和背景图，具有默认态和激活态两套完全独立的样式配置，激活时可以显示更多信息。通过全局配置中的摄像机位置、旋转半径、透视距离等参数实现丰富的3D视觉效果。支持自动播放、悬停暂停、左右控制按钮等功能。

**与其他媒体组件的区别**：
- 区别于 swswiper（轮播图）：swSwiperCard 是3D旋转卡片，每张卡片有标题和正文内容，且默认态和激活态样式独立可控；swswiper 是平面图片轮播，结构更简单，只有图片和叠加文字。
- 区别于 sw-open-video（开场视频）：swSwiperCard 是卡片轮播，sw-open-video 是单一视频播放。
- 区别于 ctVideoPanel（视频面板）：swSwiperCard 展示图片卡片，ctVideoPanel 展示视频网格。
