# iframe (swiframe)

**组件标识**: swiframe | **中文名**: iframe | **分类**: 媒体

## 描述

iframe嵌入组件，用于在大屏中嵌入外部网页或内部页面内容。支持引用其他大屏页面，提供丰富的安全权限配置（脚本、表单、同源、导航、麦克风、摄像头、全屏等），并具备边框、滚动条、关闭按钮等布局控制。适合嵌入第三方系统、报表页面或内部页面链接。

**核心功能**：
- 支持嵌入外部网页URL或内部页面
- 支持引用其他大屏页面（quoteId/quoteVersion）
- 提供脚本、表单、同源、导航等安全权限控制
- 支持麦克风、摄像头、全屏等媒体权限
- 提供可自定义位置和样式的关闭按钮
- 支持边框和滚动条控制

**与其他媒体组件的区别**：
- 区别于视频（swvideo）：本组件嵌入完整的网页内容，视频组件仅播放视频文件
- 区别于图片（swimg）：本组件嵌入可交互的网页，图片组件展示静态图片
