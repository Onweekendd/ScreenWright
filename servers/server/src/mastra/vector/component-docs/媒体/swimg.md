# 图片 (swimg)

**组件标识**: swimg | **中文名**: 图片 | **分类**: 媒体

## 描述

图片展示组件，用于在大屏中显示图片内容。提供丰富的视觉效果配置，包括三轴旋转、入场动画（多种动画类型、速度、时长、延迟、间隔控制）、8种滤镜效果（高斯模糊、亮度、对比度、灰度、色相、反色、饱和度、褐色）、阴影配置和图片预览功能。支持背景滤镜（毛玻璃效果）。

**核心功能**：
- 支持图片展示和封面配置
- 提供入场动画（opacity、slide等动画类型），可配置速度、时长、延迟和循环
- 提供高斯模糊、亮度、对比度、灰度、色相、反色、饱和度、褐色共8种滤镜效果
- 支持三轴旋转和阴影配置
- 支持图片预览功能，可配置预览宽度
- 支持背景滤镜（毛玻璃效果）

**与其他媒体组件的区别**：
- 区别于视频（swvideo）：本组件展示静态图片，视频组件播放动态视频内容
- 区别于iframe（swiframe）：本组件展示图片文件，iframe嵌入完整的网页内容
