# 轮播图 (swswiper)

**组件标识**: swswiper | **中文名**: 轮播图 | **分类**: 媒体

## 描述

用于在大屏上展示多张图片的轮播切换效果，支持自动播放、手动切换、多种切换动画方向。每张图片可叠加文字内容，支持独立的字体样式和文字阴影配置。支持卡片式或普通式轮播类型，以及水平或垂直轮播方向。通过 picStyle 配置实现三层叠加展示效果（当前图、第二层、第三层），每层可独立设置缩放和偏移。

**与其他媒体组件的区别**：
- 区别于 swSwiperCard（轮播卡片）：swswiper 专注于图片轮播展示，每张图片是一个扁平的图片+文字组合；swSwiperCard 是带有标题和正文内容的3D旋转卡片，具有默认态和激活态两套独立样式。
- 区别于 sw-open-video（开场视频）：swswiper 展示静态图片轮播，sw-open-video 展示视频内容。
- 区别于 ctVideoPanel（视频面板）：swswiper 是图片轮播，ctVideoPanel 是多视频网格布局。

## 别名/同义词

## 适用场景

首页 banner 图片展示 产品展示轮播 活动海报轮播 企业宣传图片切换 新闻焦点图 品牌形象展示 多张宣传图自动轮播 图片画廊效果
