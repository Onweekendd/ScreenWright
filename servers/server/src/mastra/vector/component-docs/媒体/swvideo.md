# 视频 (swvideo)

**组件标识**: swvideo | **中文名**: 视频 | **分类**: 媒体

## 描述

视频播放组件，用于在大屏中嵌入和播放视频内容。支持自动播放、循环播放、静音等基础播放控制，同时提供丰富的视频滤镜效果（亮度、对比度、饱和度、色相、灰度、褐色、反色、高斯模糊）和旋转、阴影等视觉效果配置。可通过封面图自定义视频未播放时的展示画面。

**核心功能**：
- 支持视频自动播放、循环播放、静音、播放速率调节
- 提供高斯模糊、亮度、对比度、灰度、色相、反色、饱和度、褐色共8种滤镜效果
- 支持三轴旋转和阴影配置
- 支持背景滤镜（毛玻璃效果）

**与其他媒体组件的区别**：
- 区别于图片（swimg）：本组件播放视频内容，图片组件展示静态图片
- 区别于音频（sw-embed-audio）：本组件播放视频（含画面），音频组件仅播放声音
