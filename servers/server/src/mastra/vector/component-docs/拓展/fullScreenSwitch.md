# 全屏切换 (fullScreenSwitch)

**组件标识**: fullScreenSwitch | **中文名**: 全屏切换 | **分类**: 扩展

## 描述

用于在大屏上提供全屏和非全屏状态切换功能的交互组件。点击后可将大屏从当前窗口模式切换到浏览器全屏模式，再次点击退出全屏。支持自定义全屏和非全屏两种状态下显示的图标，默认为放大和缩小图标。组件尺寸通常较小，放置在大屏角落位置作为功能按钮使用。

**与其他组件的区别**：
- 区别于页面刷新（pageReload）：本组件切换全屏状态，页面刷新组件刷新页面内容

## 别名/同义词

全屏切换 全屏按钮 全屏 全屏控制 退出全屏 全屏图标 全屏开关

## 适用场景

大屏全屏切换 演示模式全屏 投屏全屏控制 窗口全屏模式切换
