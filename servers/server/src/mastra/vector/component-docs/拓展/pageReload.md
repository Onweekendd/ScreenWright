# 页面刷新 (pageReload)

**组件标识**: pageReload | **中文名**: 页面刷新 | **分类**: 扩展

## 描述

用于提供大屏页面刷新功能的交互组件。支持点击刷新和自动刷新两种模式：点击模式下用户点击图标触发页面刷新，自动模式下按设定时间自动刷新页面。可自定义刷新图标的大小和透明度。组件尺寸通常较小，放置在大屏角落位置作为功能按钮使用。

**与其他组件的区别**：
- 区别于全屏切换（fullScreenSwitch）：本组件刷新页面内容，全屏切换组件切换显示模式

## 别名/同义词

页面刷新 刷新按钮 刷新 刷新组件 重载页面 页面重载 重新加载

## 适用场景

大屏刷新按钮 定时自动刷新 运维手动刷新 防缓存定时刷新 数据监控大屏刷新
