# 360全景容器v1 (photo-sphere-viewer)

**组件标识**: photo-sphere-viewer | **中文名**: 360全景容器v1 | **分类**: 扩展

## 描述

用于展示360度全景图片的交互式查看器组件。支持鼠标拖拽旋转、滚轮缩放、键盘控制等多种交互方式查看全景图片。可配置鱼眼效果、球面校正、默认视角等参数。内置导航栏提供缩放、图库、自动旋转、全屏等功能按钮。支持多张全景图片组成图库进行切换浏览，并可在全景图上添加标记点。

**与其他组件的区别**：
- 区别于图片组件（swimg）：本组件为交互式全景查看器，支持360度旋转和缩放，非静态图片展示
