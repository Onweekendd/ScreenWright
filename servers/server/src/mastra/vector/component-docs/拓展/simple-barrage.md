# 弹幕组件 (simple-barrage)

**组件标识**: simple-barrage | **中文名**: 弹幕组件 | **分类**: 扩展

## 描述

用于在大屏上实现弹幕飘屏效果的展示组件。多条文本消息以不同速度从右向左滚动飘过，支持多轨道并行展示和循环播放。可以为弹幕配置多种样式（不同颜色、字号、字体等），系统会随机分配样式给每条弹幕，营造丰富的视觉效果。支持鼠标悬停暂停功能，也可通过外部接口实时导入弹幕数据。常用于大屏互动、评论展示、活动氛围营造等场景。

**与其他组件的区别**：
- 区别于文本滚动（swScroll）：本组件为多轨道弹幕飘屏效果，文本滚动为表格轮播
