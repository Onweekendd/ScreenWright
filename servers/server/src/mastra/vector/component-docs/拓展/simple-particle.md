# 上升粒子 (simple-particle)

**组件标识**: simple-particle | **中文名**: 上升粒子 | **分类**: 扩展

## 描述

用于在大屏上展示粒子上升动画效果的装饰组件。大量小颗粒以指定方向持续运动飘升，支持配置粒子的大小、数量、运动方向（上、下、左、右）、运动速度和多色混合效果。颜色列表中可配置多种颜色随机分配给粒子，营造丰富的视觉层次。常用于大屏背景装饰、营造科技感氛围等场景。

**与其他组件的区别**：
- 区别于闪点组件（simpleStar）：本组件为运动飘升的粒子效果，闪点为固定位置闪烁的光点

## 别名/同义词

上升粒子 粒子 粒子效果 粒子动画 飘升粒子 粒子特效 飘浮粒子

## 适用场景

大屏背景科技感装饰 数据可视化粒子氛围 地图数据流效果 动态氛围营造 智慧城市数据流动
