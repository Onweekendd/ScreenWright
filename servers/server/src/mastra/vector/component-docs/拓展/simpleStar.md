# 闪点组件 (simpleStar)

**组件标识**: simpleStar | **中文名**: 闪点组件 | **分类**: 扩展

## 描述

用于在大屏上展示随机分布的闪烁光点效果的装饰组件。大量小光点在组件区域内随机分布并以闪烁动画呈现，模拟星光闪烁的效果。支持配置闪点颜色、数量和半径大小。常用于大屏背景装饰、地图上的城市节点闪烁、科技感氛围营造等场景。

**与其他组件的区别**：
- 区别于上升粒子（simple-particle）：本组件为固定位置闪烁光点，上升粒子为运动飘升效果
- 区别于散点图（echartscatter）：本组件为装饰性闪烁效果，散点图为数据可视化图表

## 别名/同义词

闪点 闪点组件 星光 星星闪烁 闪烁点 光点 闪烁粒子 亮点 闪光点

## 适用场景

大屏背景星光闪烁 地图城市节点闪烁 科技感氛围装饰 配合地图显示亮点 夜间城市效果模拟
