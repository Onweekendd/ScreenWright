# 数据容器 (sw-dataContainer)

**组件标识**: sw-dataContainer | **中文名**: 数据容器 | **分类**: 扩展

## 描述

用于接收外部数据源并转发给其他组件使用的中间容器组件。它本身不负责数据可视化展示，而是作为一个数据中转站，将获取到的数据通过回调参数传递给子组件或关联组件，实现数据的统一管理和分发。支持通过数据过滤器对原始数据进行加工处理后输出。

**与其他组件的区别**：
- 区别于其他扩展组件：本组件不负责可视化展示，仅作为数据中转站使用

## 别名/同义词

数据容器 容器 数据包装 数据适配 数据中转

## 适用场景

数据中转层 API数据分发 多组件共享数据源 数据加工处理 回调参数联动 数据统一管理
