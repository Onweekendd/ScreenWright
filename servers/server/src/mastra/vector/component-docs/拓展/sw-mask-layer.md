# 线性渐变遮罩层 (sw-mask-layer)

**组件标识**: sw-mask-layer | **中文名**: 线性渐变遮罩层 | **分类**: 扩展

## 描述

用于在大屏上叠加一层渐变遮罩效果，支持线性渐变和径向渐变两种模式。线性渐变模式下遮罩从一侧向另一侧渐变过渡，适合营造边缘渐隐效果；径向渐变模式下遮罩从中心向外扩散，适合突出中心区域内容。还可选配背景滤镜效果实现模糊和饱和度调节。常用于大屏边缘过渡处理、聚焦中心区域、以及视觉层次分离。

**与其他组件的区别**：
- 区别于上升粒子和闪点组件：本组件为静态渐变遮罩效果，非动态粒子效果

## 别名/同义词

遮罩层 渐变遮罩 线性渐变遮罩 径向渐变遮罩 蒙版 遮罩蒙版 遮罩覆盖

## 适用场景

大屏边缘渐隐 突出中心区域 背景模糊聚焦 拓扑图边缘渐变 多区域层次过渡 视觉层次分离
