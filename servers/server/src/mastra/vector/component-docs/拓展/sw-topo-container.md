# 拓扑容器 (sw-topo-container)

**组件标识**: sw-topo-container | **中文名**: 拓扑容器 | **分类**: 扩展

## 描述

用于承载和管理拓扑关系图的可视化容器组件。支持在容器内通过拖拽方式添加和排列各种子组件作为拓扑节点，并通过连线建立节点之间的关联关系。容器支持3D变换效果，包括透视、旋转、倾斜、缩放和平移，可以创建具有空间感的拓扑视图。背景支持纯色和图片两种模式，适合用于展示网络拓扑结构、系统架构关系、组织架构等场景。

**与其他组件的区别**：
- 区别于数据容器：本组件用于拓扑关系的可视化布局，数据容器仅用于数据中转
- 区别于关系图（echartgraph）：本组件支持自由拖拽布局和3D变换，关系图为ECharts自动布局

## 别名/同义词

拓扑 拓扑图 拓扑容器 关系图容器 拓扑布局 网络拓扑 节点图容器

## 适用场景

网络拓扑结构 系统架构关系 组织架构图 设备连接关系 自由拖拽布局 节点关系可视化
