# 天气 (sw-weather)

**组件标识**: sw-weather | **中文名**: 天气 | **分类**: 扩展

## 描述

用于在大屏上实时展示天气信息的组件，支持基础天气数据模式和自定义图标映射模式。基础模式下自动获取天气数据并展示，可分别控制天气图标、天气文字、温度和风力四个信息模块的显示。通过seriesTabsList可以为不同天气类型（晴、多云、阴、雨、雪等）配置对应的自定义图标。组件支持水平和垂直两种排列方向，可灵活适配各种大屏布局。

**与其他组件的区别**：
- 区别于文本组件：本组件专为天气数据设计，内置天气图标和天气类型映射

## 别名/同义词

天气组件 天气信息 天气展示 天气预报 实时天气 天气插件 气象信息

## 适用场景

智慧城市天气展示 园区气象监测 景区气象信息 楼宇智能气象面板 区域天气展示
