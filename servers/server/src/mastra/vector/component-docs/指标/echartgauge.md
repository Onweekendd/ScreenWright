# 仪表盘 (echartgauge)

**组件标识**: echartgauge | **中文名**: 仪表盘 | **分类**: 指标

## 描述

以表盘刻度和指针的形式展示单个数值的大小，类似汽车仪表盘。支持丰富的配置项，包括刻度范围、标签样式、分割线、指针颜色与长度、圆心锚点、轴线多区间颜色、动画效果、详情标签（含前缀和单位）、头像图片、底部X轴刻度等。是所有指标组件中配置项最多的组件，适合需要精确展示数值及其所处范围区间的场景。

**与其他指标组件的区别**：
- 区别于环形图（echartring）：本组件为表盘指针样式，有刻度和多区间颜色，环形图为环形进度条
- 区别于水球图（echartliquidFill）：本组件为刻度盘指针，水球图为球形波浪填充
- 区别于颜色块（swflop）：本组件为圆形刻度盘展示单值，颜色块为卡片形式展示多值
- 区别于饼图（echartpie）：本组件展示单值在范围中的位置，饼图展示多分类占比

## 别名/同义词

表盘 指针盘 刻度盘 gauge 速度表 仪表 表盘图 指标盘 量表 盘面指标

## 适用场景

设备运行状态 性能指标评分 质量合格率 温度湿度 满意度评分 速度指标 风险等级 服务器负载率 健康指数 综合评分
