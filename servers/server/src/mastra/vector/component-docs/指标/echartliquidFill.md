# 水球图 (echartliquidFill)

**组件标识**: echartliquidFill | **中文名**: 水球图 | **分类**: 指标

## 描述

以球形或自定义形状的容器内填充波浪水面来展示百分比数值，波浪高度对应占比值，具有强烈的视觉冲击力。支持波浪振幅、方向、颜色、动画、外边框、多种形状（圆形、矩形、三角形等）配置。标签支持显示系列名称和百分比数值。适合大屏展示中的核心指标、完成率、水位线等场景。

**与其他指标组件的区别**：
- 区别于环形图（echartring）：本组件为球形波浪动态填充，环形图为环形静态进度条
- 区别于仪表盘（echartgauge）：本组件为球形水波效果，仪表盘为刻度盘指针样式
- 区别于颜色块（swflop）：本组件为球形动态波浪，颜色块为平面卡片
- 区别于饼图（echartpie）：本组件展示单值占比以波浪填充，饼图展示多分类占比以扇区面积
