# 进度条 (echartprogress)

**组件标识**: echartprogress | **中文名**: 进度条 | **分类**: 指标

## 描述

以水平条形展示当前数值相对于最大值的进度比例。支持渐变色进度条、前缀和单位文本标注、头部图片装饰以及X轴刻度线配置。数据包含 value 当前值、max 最大值和 min 最小值三个字段，可灵活计算百分比进度。常用于大屏中展示任务完成率、目标达成率、资源占用率等场景。

**与其他进度相关组件的区别**：
- 区别于文字组件 swProgress：本组件基于 ECharts 渲染，支持渐变色和复杂样式；swProgress 为纯文字进度条
- 区别于翻牌器：本组件展示进度比例而非单个数值

## 别名/同义词

进度条 进度 比例条 完成率条 任务进度 目标达成条 百分比条 渐变进度条 bar progress

## 适用场景

任务完成进度 目标达成率 资源占用率 销售目标完成比 项目进度展示 KPI达成率 负载率显示 下载进度 审核进度 培训完成率
