# 环形图 (echartring)

**组件标识**: echartring | **中文名**: 环形图 | **分类**: 指标

## 描述

用环形进度条展示单个数值占总量的比例。中心显示当前值和百分比，环体支持渐变色配置。适合展示完成率、达成率、进度等单值占比场景。数据只需一个 value 和一个 total 即可渲染。

**与其他指标组件的区别**：
- 区别于仪表盘（echartgauge）：本组件为环形进度条样式，仪表盘为表盘刻度样式带指针
- 区别于水球图（echartliquidFill）：本组件为环形静态进度，水球图为球形波浪动态填充
- 区别于饼图（echartpie）：本组件只展示单值占比，饼图展示多分类占比

## 别名/同义词

环形进度图 环形占比图 进度环 圆环图 进度条环形 完成率图 达成率图 百分比环 单值占比

## 适用场景

项目完成率 KPI达成率 任务进度 目标完成百分比 资源使用率 考勤率 合格率 预算执行率
