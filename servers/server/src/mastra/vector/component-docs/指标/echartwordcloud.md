# 字符云 (echartwordcloud)

**组件标识**: echartwordcloud | **中文名**: 字符云 | **分类**: 指标

## 描述

将文本关键词按权重值大小以不同字号密集排列展示，形成视觉冲击力强的词云效果。词的字号越大表示权重越高，支持旋转角度、网格间距、形状和遮罩图片等丰富的布局配置。适合展示热词分布、关键词频率、用户标签等场景。

**与其他指标组件的区别**：
- 区别于文字组件（swText2、swtext）：本组件以词云形式展示多个关键词及权重，文字组件展示固定文本内容
- 区别于排名图（echartrank）：本组件以视觉密度和字号突出重点，排名图以条形排列展示排名

## 别名/同义词

词云 标签云 文字云 热词图 关键词云 标签聚合 词语分布 热门词云 舆情词云 文本标签可视化

## 适用场景

热词排行榜 用户画像标签 搜索关键词 舆情热词分析 商品标签分布 话题热度 新闻关键词 兴趣标签展示 弹幕热词 社交媒体话题分析
