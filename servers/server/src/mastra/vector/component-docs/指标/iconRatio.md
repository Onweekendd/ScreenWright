# 图标占比图 (iconRatio)

**组件标识**: iconRatio | **中文名**: 图标占比图 | **分类**: 指标

## 描述

用图标（图片或字体图标）直观展示各项数据的占比关系。每个数据项对应一个可自定义的图标，图标大小和位置反映数值比例。支持全局布局配置（行列数、小数位数）和每个图标独立配置（图标字体、大小、颜色、图片地址、偏移等）。适合展示性别比例、分类占比等需要图形化辅助说明的场景。

**与其他指标组件的区别**：
- 区别于饼图（echartpie）：本组件用图标表示占比，饼图用扇区面积表示
- 区别于环形图（echartring）：本组件展示多个类目的占比并配以图标，环形图只展示单值占总量
- 区别于颜色块（swflop）：本组件侧重用图标可视化占比，颜色块侧重用背景色区分数值

## 别名/同义词

图标比例图 图标占比 图标分布 图标统计 比例图 占比可视化 图标数据图 男女比例图 图标对比

## 适用场景

性别比例展示 分类占比可视化 男女分布 用户类型占比 部门人员构成 客户分类比例 产品类别占比 团队成员分布
