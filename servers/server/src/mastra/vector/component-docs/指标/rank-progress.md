# 排名进度 (rank-progress)

**组件标识**: rank-progress | **中文名**: 排名进度 | **分类**: 指标

## 描述

以列表形式展示多项数据的排名和进度，每行显示一个条目的名称、进度条和数值。进度条长度按数值比例渲染，支持配置条形宽度、高度和外边距。名称和数值分别可独立配置字体、字号、颜色、字重、字间距等文字样式，并支持文字阴影效果。列表支持滚动展示，可设置显示条数和滚动类型。每个排名位置可独立配置颜色，前三名常用金、银、铜色区分。圆形标记可在进度条起点展示序号或装饰。适用于各类排名、竞对对比、TOP N 数据展示等场景。
