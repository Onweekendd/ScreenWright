# 栅格进度条 (rasterProgressBar)

**组件标识**: rasterProgressBar | **中文名**: 栅格进度条 | **分类**: 指标

## 描述

以分段栅格条的形式展示单个进度值，将进度条分成若干等宽的小格子来可视化比例。支持配置栅格分段数量、圆角、前后景透明度和间隔。前景色和背景色均可自定义，前景支持线性渐变。数值默认以百分比形式展示，支持自定义数值类型和极值范围。具备完整的文字标签系统，包括系列文字、单位和标签三套独立的样式配置，每套均可分别设置字体、字号、颜色、偏移等。还支持背景图片标牌和区间分段样式，当数值落入不同区间时可展示不同的颜色和标牌图片，用于告警分级等场景。

## 别名/同义词

栅格条 格子进度 分段进度条 网格进度 格子条 像素进度 条格进度 分块进度 栅格百分比 格子百分比 离散进度条

## 适用场景

单个指标完成率展示 项目进度百分比 设备运行状态 监控告警分级（按区间变色） 资源使用率 考核得分可视化 目标达成率 容量使用百分比 健康度指标 数据质量评分
