# 分类占比条 (sortRatioBar)

**组件标识**: sortRatioBar | **中文名**: 分类占比条 | **分类**: 指标

## 描述

以横向分段条的形式展示多个分类的占比数据，每个分类对应条形中的一段，长度按数值比例分配。支持为每个系列独立配置渐变背景色、文字样式、单位和透明度。条形上方或下方可显示系列名称标签和数值标签，数值支持自定义小数位数。各系列之间可配置间隔距离，整体背景色可自定义。适用于展示分类数据的组成比例和对比关系，如设备状态分布、任务完成情况统计等场景。

## 别名/同义词

占比条 分类占比 条形占比 比例条 横向占比条 分类比例条 多段占比条 分段条 分段占比 条形比例 组成占比条 状态占比条

## 适用场景

设备状态分布（剩余数/使用数/故障数） 任务完成情况统计 资源使用比例展示 库存分类占比 资金分配比例 项目进度分类展示 人员状态分布 产能利用率展示 渠道占比分析
