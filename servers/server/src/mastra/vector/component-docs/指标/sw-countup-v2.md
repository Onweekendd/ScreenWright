# 翻牌器v2 (sw-countup-v2)

**组件标识**: sw-countup-v2 | **中文名**: 翻牌器v2 | **分类**: 指标

## 描述

以数字滚动翻转动画展示单个关键数值指标。支持自动播放翻牌动画、千分位分组、小数位数控制、数字位数补齐等功能。数字部分支持边框样式和图片样式两种渲染模式，可配置数字宽度、高度、间距、渐变色等丰富样式。前缀和后缀文本可独立设置字体、颜色、对齐方式。还支持自动递增功能，可在指定范围内随机递增数值，适合大屏动态展示。

**与其他翻牌器的区别**：
- 区别于翻牌器v3（swFlopPerformance）：v2 支持小数点大小(pointSize)、数字宽高(spanWidth/spanHeight)、数字间距(spanMangin)、递增总数(incrementTotal)等独有配置
- 区别于 ft-countup（v1）：v2 为升级版本，配置项更丰富

## 别名/同义词

翻牌器 数字翻牌 滚动数字 计数器 数字动画 数值动画 数字滚动 翻牌计数 flop counter countup

## 适用场景

实时数据展示 销售额数字 访客数统计 订单数量 金额大屏 数字看板 核心指标展示 实时计数 KPI数值 季度目标数
