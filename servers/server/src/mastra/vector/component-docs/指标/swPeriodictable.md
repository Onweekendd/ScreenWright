# 图片墙 (swPeriodictable)

**组件标识**: swPeriodictable | **中文名**: 图片墙 | **分类**: 指标

## 描述

以网格布局展示多张图片的组件，类似元素周期表式排列。支持配置每行显示的图片数量、图片尺寸、行列间距和整体偏移量，以及动画切换间隔时间。图片列表通过 images 数组配置，每项包含图片地址。默认预置大量图片占位，可根据需要替换为实际图片路径。该组件无数据字段，所有配置均在 option 中完成。

**与其他图片相关组件的区别**：
- 区别于普通图片组件：本组件以网格形式排列多张图片，支持行列布局和间距控制
- 区别于轮播组件：本组件同时展示所有图片而非逐张切换
