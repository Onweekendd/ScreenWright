# 环比同比图 (swdynamicratio)

**组件标识**: swdynamicratio | **中文名**: 环比同比图 | **分类**: 指标

## 描述

同时展示数值的环比和同比变化情况。通过阈值(thresholdValue)判断数值正负，分别用不同颜色和图标方向表示增长或下降趋势。该组件的许多配置字段为数组类型，数组索引0对应环比维度，索引1对应同比维度，可独立控制两个维度的字体、颜色、大小、阴影、图标等样式。支持选中态高亮、阴影效果和渐变文字颜色，适合大屏中展示关键业务指标的同比环比变化。

**与其他指标组件的区别**：
- 区别于翻牌器：本组件侧重同比环比对比展示，而非单一数值动画
- 区别于普通文字组件：本组件内置环比同比逻辑，支持正负自动着色和图标切换
