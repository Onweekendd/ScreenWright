# 折叠面板 (customCollapse)

**组件标识**: customCollapse | **中文名**: 折叠面板 | **分类**: 文字

## 描述

手风琴式折叠展开面板组件，每个面板项可包含图片、视频或富文本内容，点击标题区域展开或折叠内容。支持自定义标题样式（字体、颜色、阴影、背景图片）和内容样式，可配置默认展开项。区别于卡片滚动（swcollection），折叠面板为垂直方向的手动展开交互，不支持自动滚动。区别于轮播表格（swScroll），折叠面板每项内容丰富（支持图片、视频、文本），不是简单的数据表格。
