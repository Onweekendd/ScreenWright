# 自定义列表 (customTableList)

**组件标识**: customTableList | **中文名**: 自定义列表 | **分类**: 文字

## 描述

自由布局的卡片式列表组件，每条数据以独立卡片形式展示，卡片内的文本元素可自由定位。与轮播表格（swScroll）和进度条表格（swProgress）的标准行列布局不同，本组件支持在卡片内任意放置标签文字和数据字段，通过坐标偏移精确控制每个元素的位置和样式，适合需要个性化排版的信息列表场景。支持默认态、悬停态、选中态三种状态的独立样式配置。

## 别名/同义词

## 适用场景
