# 进度条表格 (swProgress)

**组件标识**: swProgress | **中文名**: 进度条表格 | **分类**: 文字

## 描述

带有进度条展示的表格组件，在表格的数值列中以内嵌进度条的形式直观展示比例数据。继承轮播表格（swScroll）的大部分配置能力，额外支持百分比显示和小数位保留，数值列自动渲染为进度条样式。与轮播表格相比，本组件专为比例型数据设计，数值列自带进度条可视化。与自定义列表（customTableList）相比，本组件是标准行列表格布局。

## 别名/同义词

进度表格 进度条列表 比例表格 百分比表格 进度表 比例列表 数据进度 指标进度表 横向进度表格

## 适用场景

各地区学历占比对比 各部门完成率展示 分类占比数据表格 指标达成率列表 比例数据对比展示 百分比分布表格 多维度占比数据 预算执行率表格 投票结果比例展示
