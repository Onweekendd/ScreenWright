# 富文本 (swRichtext)

**组件标识**: swRichtext | **中文名**: 富文本 | **分类**: 文字

## 描述

支持HTML富文本内容的文字展示组件，可以显示带格式的文本段落，包括不同字号、颜色、加粗、斜体等样式混排。支持文字动画效果和滚动展示，适合需要丰富排版样式的场景。该组件通过HTML内容字段承载所有文本样式，不依赖外部数据源时可静态展示。

**与其他文字组件的区别**：
- 区别于文本框（swtext）：本组件支持HTML富文本格式混排，文本框为纯文本展示
- 区别于多行文本（swmultiLine）：本组件以HTML内容为整体渲染，多行文本按数据行逐行渲染
- 区别于实时时间（swdatetime）：本组件显示自定义富文本内容，实时时间自动显示当前时间

## 别名/同义词

产品介绍文本 说明文字展示 公告信息 图文混排内容 带格式的描述信息 营销文案展示 多样式混排文本 大屏说明文档
