# 轮播表格 (swScroll)

**组件标识**: swScroll | **中文名**: 轮播表格 | **分类**: 文字

## 描述

自动滚动的表格组件，用于在大屏上以轮播方式展示动态更新的列表数据。支持表头、行序号、列定义、选中高亮、状态图标、后缀单位等丰富的表格样式配置，数据超出可视区域时自动向上滚动。与进度条表格（swProgress）相比，本组件侧重通用文本内容的轮播展示，不含进度条和百分比功能。与自定义列表（customTableList）相比，本组件是标准行列表格布局，customTableList是自由布局的卡片列表。

## 别名/同义词

滚动表格 轮播列表 自动滚动表 滚动列表 表格轮播 列表滚动 滚屏表格 跑马灯表格 消息滚动 实时信息表

## 适用场景

实时告警信息滚动展示 事件列表轮播 日志信息自动滚动 监控数据表格动态更新 排班信息轮播 公告列表滚动展示 设备状态实时列表 异常信息滚动提醒 工单列表自动刷新
