# 状态文本框 (swText2)

**组件标识**: swText2 | **中文名**: 状态文本框 | **分类**: 文字

## 描述

根据数据值自动切换显示样式的文本组件，支持多条件样式映射。可配置多种状态卡片（cardList），每张卡片定义一组映射值和对应的字体、颜色、背景样式，组件根据数据值自动匹配对应样式展示。区别于普通文本框（swtext），状态文本框的核心能力是条件样式切换，适合展示设备状态、告警等级、任务进度等需要根据值变色的场景。区别于多行文本（swmultiLine），状态文本框为单行展示，不支持多段落内容。

## 别名/同义词

状态文本 条件文本 动态样式文本 根据值变色 条件样式 告警状态文本 状态标签 状态显示 多样式文本

## 适用场景

设备在线离线状态展示 告警等级颜色区分 任务完成状态显示 审批流程状态 展会参展状态 考勤状态标记 工单处理状态 服务运行状态
