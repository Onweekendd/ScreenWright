# 词云 (swTextWordCloud)

**组件标识**: swTextWordCloud | **中文名**: 词云 | **分类**: 文字

## 描述

以词语大小和颜色展示文本数据权重的可视化组件，支持3D球形旋转交互。每个词语根据关联数值（value）决定显示大小，数值越大文字越大，支持拖拽控制和自动旋转。区别于其他文字组件，词云不展示段落文本或表格数据，而是将多组词语文本数据以视觉化权重方式呈现，适合展示搜索热词、舆情关键词、城市排名等场景。

## 别名/同义词

词云图 文字云 标签云 词语云 3D词云 球形词云 热词云 关键词云 tag cloud word cloud

## 适用场景

搜索热词展示 舆情关键词分析 城市热度排名 用户关注点分析 品牌关键词展示 话题热度展示 标签统计 员工技能分布 兴趣爱好分布
