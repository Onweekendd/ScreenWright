# 卡片滚动 (swcollection)

**组件标识**: swcollection | **中文名**: 卡片滚动 | **分类**: 文字

## 描述

以卡片形式水平滚动展示多条数据的组件，每张卡片包含图片或视频资源和标题文字。支持自动轮播、循环播放和静音控制，可自定义卡片数量、间距、背景样式和滚动方向。区别于轮播表格（swScroll），卡片滚动以视觉化卡片形式展示，每条数据独立成卡，更适合展示人员信息、产品推荐、新闻轮播等图文结合的场景。区别于折叠面板（customCollapse），卡片滚动为自动横向滚动，不支持展开折叠交互。

## 别名/同义词

卡片轮播 滚动卡片 横向卡片 图片卡片轮播 卡片展示 图文滚动 卡片滑动 card carousel

## 适用场景

人员信息轮播展示 产品推荐卡片 新闻图片轮播 项目案例展示 荣誉展示滚动 团队成员介绍 合作伙伴展示 活动海报轮播

## 不适用场景

纯文字列表展示 多列数据对比 大量文本段落展示
