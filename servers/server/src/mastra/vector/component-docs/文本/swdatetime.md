# 实时时间 (swdatetime)

**组件标识**: swdatetime | **中文名**: 实时时间 | **分类**: 文字

## 描述

自动显示当前系统日期和时间，无需手动输入或绑定数据源。通过格式字符串自定义显示样式，支持年月日时分秒等多种时间格式组合。该组件为纯展示组件，不需要数据绑定，始终显示实时更新的时间信息。

**与其他文字组件的区别**：
- 区别于文本框（swtext）：本组件自动显示实时时间，文本框显示静态或用户输入的文字
- 区别于多行文本（swmultiLine）：本组件仅显示单行时间，多行文本支持多段落和滚动
- 区别于富文本（swRichtext）：本组件仅显示格式化时间，富文本支持HTML内容和富文本编辑
