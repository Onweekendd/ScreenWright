# 多行文本 (swmultiLine)

**组件标识**: swmultiLine | **中文名**: 多行文本 | **分类**: 文字

## 描述

以多行列表形式展示文本内容，每个数据项为一行文字段落，支持为每行配置前缀图标。提供丰富的文本样式设置，包括字体颜色渐变、文字阴影、行高、首行缩进等排版功能，以及自动滚动展示能力。适合需要逐行展示多条文字信息的场景，如滚动公告、信息列表等。

**与其他文字组件的区别**：
- 区别于文本框（swtext）：本组件支持多行数据逐行渲染和图标前缀，文本框为单条文本展示
- 区别于富文本（swRichtext）：本组件按数据行逐行渲染，富文本以HTML内容整体渲染
- 区别于实时时间（swdatetime）：本组件显示自定义多行文本，实时时间自动显示当前时间
- 支持文字阴影和渐变色等高级效果，是文字组件中样式配置最丰富的
