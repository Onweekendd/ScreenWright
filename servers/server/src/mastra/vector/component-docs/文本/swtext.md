# 文本框/跑马灯/超链接 (swtext)

**组件标识**: swtext | **中文名**: 文本框/跑马灯/超链接 | **分类**: 文字

## 描述

通用的单行文本展示组件，通过type字段切换三种模式：文本框模式显示普通静态文字，跑马灯模式实现文字滚动效果，超链接模式显示可点击跳转的链接文字。支持丰富的字体样式和阴影效果配置，是大屏中最常用的基础文字组件。三种模式共享相同的字体和样式配置，但各有专属功能。

**三种模式的区别**：
- 文本框模式（text）：静态展示文字，适合标题和固定文案
- 跑马灯模式（marquee）：文字自动滚动，适合长文字滚动展示
- 超链接模式（link）：可点击跳转，适合导航和外部链接

**与其他文字组件的区别**：
- 区别于多行文本（swmultiLine）：本组件为单条文本展示，多行文本支持多条数据逐行渲染
- 区别于富文本（swRichtext）：本组件为纯文本展示，富文本支持HTML格式混排
- 区别于实时时间（swdatetime）：本组件显示自定义文本，实时时间自动显示当前时间
