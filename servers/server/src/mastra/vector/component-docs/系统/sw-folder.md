# 分组 (sw-folder)

**组件标识**: sw-folder | **中文名**: 分组 | **分类**: 系统

## 描述

分组是一种容器类系统组件，用于将多个组件在空间上归为一组，方便统一移动、缩放和管理层级结构。分组内可以容纳任意数量的普通组件。

**与其他容器组件的区别**：
- 区别于动态面板（sw-panel）：分组没有多状态切换能力，只是空间上的归组，不能嵌套进分组或动态面板内部使用分组嵌套分组
- 区别于终端交互（terminal-control）：分组无跨屏通信能力，纯粹用于组织布局

## 别名/同义词

分组 组合 编组 图层分组 组件组 group 容器 归组

## 适用场景

多组件统一移动 统一缩放一组元素 组织页面布局结构 将相关组件归为同一层级 批量对齐操作 简化图层面板管理
