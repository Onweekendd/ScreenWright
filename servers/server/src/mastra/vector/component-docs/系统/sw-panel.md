# 动态面板 (sw-panel)

**组件标识**: sw-panel | **中文名**: 动态面板 | **分类**: 系统 > 面板

## 描述

动态面板是具有多状态切换能力的容器组件。一个动态面板可以包含多个相互独立的状态，每个状态内可以放置不同的子组件（包括分组和嵌套动态面板）。支持轮播自动切换、手势滑动、卡片模式展示、动画过渡和自定义弹出位置等功能，常用于制作 Tab 切换、步骤流程、弹窗面板、轮播展示等交互效果。

**与其他容器组件的区别**：
- 区别于分组（sw-folder）：分组无状态切换，动态面板每个状态内容完全独立
- 区别于终端交互（terminal-control）：动态面板用于普通大屏内切换展示，终端交互专门用于跨屏 WebSocket 通信场景

## 别名/同义词

动态面板 多状态面板 Tab面板 切换面板 状态面板 弹窗 弹出面板 轮播面板 卡片轮播 场景面板

## 适用场景

Tab页签切换 步骤流程展示 弹窗弹出效果 轮播内容切换 多视图状态管理 手势滑动展示 卡片轮播效果 模态弹窗 详情面板展开
