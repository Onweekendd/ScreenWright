# 终端交互 (terminal-control)

**组件标识**: terminal-control | **中文名**: 终端交互 | **分类**: 系统 > 面板

## 描述

终端交互是一种特殊的容器面板，结构与动态面板相似，内部同样可容纳多个子组件和状态。其核心特性在于：终端交互面板内的组件所配置的控制事件，可以通过 WebSocket 协议发送到大屏运行时，从而触发主大屏中任意组件的事件，实现跨屏通信与远程控制。典型用途是制作独立的操控端或遥控界面，让操作人员通过终端屏幕远程控制投影大屏上的组件行为。

**与其他容器组件的区别**：
- 区别于动态面板（sw-panel）：动态面板只在本大屏内切换状态，终端交互具备 WebSocket 跨屏事件传递能力
- 区别于分组（sw-folder）：分组无通信能力，终端交互专用于跨屏控制场景

## 别名/同义词

终端交互 终端面板 控制面板 跨屏控制 远程控制 WebSocket面板 操控端 遥控界面 encode面板

## 适用场景

跨屏远程控制 操控端制作 WebSocket事件触发 大屏联动控制 独立遥控界面 多屏协同展示 投屏控制
